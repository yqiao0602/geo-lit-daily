### 🔥 ⭐⭐⭐⭐ Harness Learning Enables Generalizable Test-Time Adaptation
**9/10** · Alvin Zhang、Xuecheng Liu、Zixuan Wang、Fahim Tajwar、Daman Arora、Ruslan Salakhutdinov · arXiv · 2026-09-28 · [原文](https://arxiv.org/abs/2609.35738v1) · [PDF](https://arxiv.org/pdf/2609.35738v1)
*入选：RL×LLM方法*

> 📄 **摘要**：A language-model agent is jointly defined by its model and its harness, the executable program that organizes model calls, tool use, and information flow. Because different tasks call for different ways of organizing these operations, the harness needs to be adapted using feedback from the task at hand. We introduce harness learning, which trains a proposer model to revise a solver's harness using execution feedback. We formulate this process as meta-learning over executable programs, with harness revisions playing the role of weight updates in gradient-based adaptation. We train the proposer with reinforcement learning, using the task performance of revised harnesses as the reward. At test time, the proposer uses feedback from successive executions on a new task to refine the harness, without performing any parameter-space update. Experiments on reasoning and multi-hop question answering show that harness learning improves revision quality and that the ability to adapt at test time transfers to unseen tasks. Policies trained on individual revisions can continue improving harnesses over multiple rounds, while the benefits of training on revision sequences vary across settings. These findings suggest a path towards continually learning agents that turn accumulated experience into generalizable improvements.

**一句话**：提出 harness learning，训练 proposer 模型利用执行反馈修改 solver 的 harness（组织模型调用、工具使用和信息流的可执行程序），实现无需参数更新的测试时自适应并迁移到未见任务。

痛点：语言模型 agent 的能力不仅由模型决定，还由组织模型调用、工具使用和信息流的 harness 决定，不同任务需要不同 harness，但测试时无法更新参数。方法：把 harness 修改形式化为可执行程序上的元学习，harness 修订扮演梯度适配中的权重更新角色；用强化学习以修改后 harness 的任务表现为奖励训练 proposer，测试时仅靠连续执行反馈迭代精炼 harness。结果：在推理和多跳问答上提升修订质量，测试时自适应能力可迁移到未见任务，多轮修订可持续改进 harness。

> 🔗 **与课题**：① 任务分解/工作流推理：harness 本质是可执行的 workflow，proposer 根据执行反馈修订模型调用、tool use 与信息流组织，等价于学习“任务→工作流结构”的推理与重规划。② 工作流→结构化表示：论文把 harness 作为可编辑的可执行程序，直接研究工作流依赖组织与结构修订，对应结构化/依赖/DAG 生成。③ 能力迁移：核心贡献是 test-time adaptation 迁移到 unseen tasks，在连续执行反馈中泛化，正对应 GEE→QGIS、源域→目标域的迁移保持率问题。④ Workflow→QGIS Operator 落地：harness 组织 tool use，修订过程可视为在任务反馈下选择/连接工具，与 QGIS operator grounding 同构。⑤ 结构化 QGIS 图生成：harness 程序可类比 processes+links 的可执行图，修改 harness 即修改链接与依赖，提供生成后迭代修正协议。⑥ 训练/后训练：用 RL 以任务表现训练 proposer，属于绑定 tool/workflow 场景的偏好与 RL，不是纯 RL 算法改进。⑦ 评测：用任务性能、修改质量和跨任务迁移衡量，可借鉴其 transfer retention 评测思路。

💡 **启发**：可直接借用“proposer-reviser + execution feedback”闭环，把 QGIS 生成的 processes+links 图当作可执行 harness，用执行报错/部分成功作为 reward 做多轮修订；并用 harness 修订替代权重更新实现测试时跨任务适配。

⚠️ **局限**：实验限于推理与多跳问答，未验证真实 GIS/tool 生态与长程执行错误下的稳定性，且 harness 修改空间与 QGIS 算子 schema 差异可能影响直接迁移。

🚨 **为什么必须重视**：它与核心科学问题高度撞车——同样在问工作流结构能否通过执行反馈在未见任务上自适应并迁移，且给出无需参数更新的 test-time harness 修订协议，可直接用于 GEE→QGIS 迁移。若被他人先迁移到工具/工作流 grounding 场景，会直接覆盖本课题的 ②③④⑤ 环节。其 proposer+RL 训练范式可作为竞品基线或直接复用。

### 🔥 ⭐⭐⭐⭐ From Experience to Expertise: Adoption-Aware Memory Learning for Data-Scarce NPU Kernel Synthesis
**8/10** · Longxiao Fan、Tao Zhang、Han Yan、Jiajun Li、Mingcong Song、Guoping Long · arXiv · 2026-09-28 · [原文](https://arxiv.org/abs/2609.35568v1) · [PDF](https://arxiv.org/pdf/2609.35568v1)
*入选：能力迁移*

> 📄 **摘要**：High-performance kernels underpin efficient accelerator execution but require expert tuning and lengthy manual optimization cycles. LLM coding agents promise automation, yet their CUDA knowledge transfers poorly to data-scarce domain-specific architectures (DSAs) such as NPUs, whose execution models and memory hierarchies differ substantially from those of GPUs. To address this transfer gap, post-training methods adapt LLMs to NPU programming but depend on scarce expert data and substantial training compute. Memory-learning agents instead adapt through external memory, but their uniform credit assignment gives adopted and unused experiences the same reward target, potentially biasing subsequent retrieval rankings. Moreover, when learned values guide only retrieval, high-value experiences that generalize across operators must be retrieved repeatedly rather than retained in context, thereby increasing retrieval overhead and weakening cross-task guidance. We therefore present SAGE, a persistent self-improving agent for NPU kernel synthesis. Adoption-Traced Utility estimation (ATU) combines explicit adoption records with kernel evaluation outcomes for adoption-aware credit assignment. Utility-Gated Consolidation (UGC) uses positive utility and repeated adoption across operators to select and abstract reusable rules into a bounded resident context. On NPUKernelBench, SAGE achieves a 95.5% execution rate versus 84.1% for the strongest controlled baseline, with 86.9% of solved operators outperforming torch_npu. With GLM-5.3, SAGE achieves a 43.99x speedup over the torch_npu reference on sparse flash attention. These results show that adoption-aware credit assignment and selective consolidation enable agents to accumulate and reuse hardware-specific knowledge across tasks.

**一句话**：提出 SAGE——一个持久自改进的 LLM 智能体，用「采纳感知效用估计(ATU)」与「效用门控巩固(UGC)」从经验中学习可复用规则，用于数据稀缺的 NPU kernel 合成。

痛点：LLM 编码智能体的 CUDA 知识难以迁移到 NPU 这类数据稀缺的领域专用架构(DSA)，后训练方法又依赖稀缺专家数据与大量算力；而既有记忆学习智能体对所有经验统一信用分配，会污染检索排名，且高价值经验只能反复检索而非驻留上下文。方法：ATU 把显式「采纳记录」与 kernel 执行评测结果结合做采纳感知的信用分配，UGC 依据正效用与跨算子重复采纳，将可泛化经验抽象为规则写入有界常驻上下文。结果：在 NPUKernelBench 上执行率达 95.5%，显著高于最强受控基线的 84.1%。

> 🔗 **与课题**：③能力迁移：论文的核心正是「源平台(GPU/CUDA)→目标平台(NPU)」的跨架构能力迁移实证，与课题 GEE→QGIS 的跨平台迁移同构，且明确指出统一信用分配对迁移检索排序的污染。⑥训练/后训练：以外部记忆+自改进替代依赖稀缺数据的后训练，可对应课题中把 GEE 工作流推理知识固化为「内部可迁移工作流知识」的手段（记忆/经验库 vs LoRA/蒸馏）。④grounding：kernel 合成本质是面向特定硬件算子/执行模型的落地生成，对应 Workflow→QGIS Operator grounding 中对目标算子语义与执行约束的对齐。⑤结构化生成：UGC 把跨算子可复用经验抽象为规则并组织进常驻上下文，可类比工作流步骤间的依赖组织与复用结构形成。⑦评测：用执行成功率与受控基线对比来度量迁移后落地可用率，可直接映射课题的执行成功率/落地可用率指标。

💡 **启发**：把「是否被实际采纳(adoption record)」与「执行结果」联合作为信用信号，避免高检索分但无用的经验污染后续检索——可直接搬来做 GEE→QGIS 迁移的经验池/规则库排序；用「跨任务重复采纳+正效用」的门控条件把泛化经验抽象成常驻规则，等价于把工作流推理知识固化为可迁移上下文而非每次都重新检索。

⚠️ **局限**：NPU/CUDA 与 GIS 平台在语义与依赖结构上差异仍大，其规则抽象机制能否支持需输出 processes+links 依赖闭合图的 QGIS 工作流尚待验证；摘要未给出消融细节。

🚨 **为什么必须重视**：与本课题 Route-2「源域→目标域能力迁移 + 记忆/经验固化」直接撞车，是跨平台算子/代码能力迁移的同期实证竞品。它给出的「采纳感知信用分配 + 效用门控经验巩固」协议可直接借用到 GEE→QGIS 迁移的经验/规则库设计中，属于必须尽快精读并纳入对比的路线。

### 🔥 ⭐⭐⭐⭐ From Migration to Calibration: Preserving Agent Capabilities across Models, Jurisdictions, and Scale
**8/10** · Yaxiao Liu、Pengbo Liu、Yiwen Liu、Yihua Guan、Jiaxing Song · arXiv · 2026-09-28 · [原文](https://arxiv.org/abs/2609.35149v1) · [PDF](https://arxiv.org/pdf/2609.35149v1)
*入选：RL×LLM方法*

> 📄 **摘要**：Agents need calibration when deployment conditions change: replacing a driving model, including a foundation-to-post-trained transition; crossing jurisdictions; or scaling across heterogeneous markets and sources. Interface compatibility alone does not establish capability retention or target-contract satisfaction. We formulate agent calibration as constrained behavioral adaptation across three interacting layers: information preservation, harness adaptation, and user acceptance; the layers apply to every scenario, not one-to-one to the three. The basic objective is non-degradation on prespecified capability measures while satisfying target requirements; aggregate improvement is stronger. Information calibration preserves independently validated source content still applicable to the target task. Harness calibration aligns observable artifacts at semantic checkpoints and repairs them through iteration, tool substitution, or local replanning within explicit budgets. User calibration enforces recipient-specific output contracts: templates, schemas, and section-level preferences. A global e-commerce example shows how shared standards coexist with site- and market-specific adapters and validation. We distinguish trainable policies from frozen-backbone configuration or controller optimization, and evidence verification from relative judgment and DPO/GRPO optimization. Recent harness-transfer and judge-validity studies motivate target-native execution records, separate audits of task validity and near-tie ranking, and matched target-native optimization controls. We propose held-out evaluations for model changes, cross-border adaptation, and scale, including a factorial test of source evidence and checkpoint repair and group-level reporting to prevent aggregate gains from masking local failures. This is a methodological proposal; implementation and empirical validation remain future work.

**一句话**：提出"智能体校准（agent calibration）"框架，研究在更换模型（含基础模型→后训练模型）、跨辖区、跨规模部署时如何通过信息、装置（harness）、用户三层校准保持智能体能力不退化。

痛点是部署条件变化时接口兼容并不等于能力保持或满足目标契约；方法上把 agent calibration 形式化为三层交互的约束性行为适配——信息保持（保留仍适用于目标任务的源侧内容）、harness 适配（在语义检查点上对齐产物，并通过迭代、工具替换或预算内局部重规划修复）、用户校准（模板/schema/段落级偏好等输出契约），基本目标是在预设能力度量上不退化并满足目标要求；结果层面给出全球电商的共享标准+站点/市场适配器示例，并区分可训练策略与冻结骨干配置/控制器优化、证据验证与相对判断及 DPO/GRPO 优化，倡导 target-native 执行记录与分离审计。

> 🔗 **与课题**：支撑环节③（能力迁移，源域→目标域）：论文把"模型替换、foundation→post-trained 过渡"直接当作迁移场景，并提出"在预设能力度量上不退化、可聚合提升"的迁移保持判据，与我们要的 transfer retention 同构；支撑环节⑦（评测）：其 target-native execution records、分离审计、非退化 vs 目标契约双判据可直接改造为迁移保持率、QGIS 落地可用率指标；支撑环节④（工具/算子落地）：harness calibration 中的 tool substitution 与预算内 local replanning 对应落地阶段的算子替换与依赖重规划；支撑环节⑥（训练/后训练）：明确区分可训练策略、冻结骨干配置与控制器优化，并界定 DPO/GRPO 何时适用、何时只是相对判断而非证据验证；同时保留"信息保持层"这一可替换的语义中间层视角，恰好回应我们"不依赖显式 L3 语义层"的假设。

💡 **启发**：可直接偷用其"非退化 + 目标契约满足"双判据与 target-native execution records 作为 GEE→QGIS 迁移保持率的评测协议；把三层校准映射为：workflow 知识保持（信息层）、结构化图适配与算子替换/重规划（harness 层）、QGIS processes+links 的 schema 级输出契约（用户层）。

⚠️ **局限**：属框架/立场性论述，缺乏覆盖多任务的系统实证与可复现指标定义，示例仅限全球电商，引用时须注意其结论尚未在真实工具/代码场景验证。

🚨 **为什么必须重视**：该文与核心科学问题正面撞车——它把"换模型/跨域后能力能否保持"提升为一等研究对象并给出评测契约，正是我们 Route-2 的迁移保持率命题；其 non-degradation 判据、harness 适配与 tool substitution 机制可直接借用为实现与基线，若不精读很可能在相关工作与实验设计上重复造轮子并被指遗漏；同时它提供了我们评测环节（保持率、落地可用率）现成的指标语汇。

### ⭐⭐⭐⭐ Draft-KV: Learning Useful Latent Communication Between Language Models
**7/10** · Linquan Wu、Shichang Meng、Tianxiang Jiang、Haoyu Yang、Peng Zhong、Fengming Zhu · arXiv · 2026-09-28 · [原文](https://arxiv.org/abs/2609.34754v1) · [PDF](https://arxiv.org/pdf/2609.34754v1)
*入选：能力迁移*

> 📄 **摘要**：Latent communication passes internal states between language models instead of decoded text, but higher receiver accuracy does not show that the receiver used the message content. Across five method-dataset pairs, replacing each message with one from an unrelated question changes accuracy by at most 0.60 points, even when communication adds 15.44 points over the receiver alone. Thus the interface can supply the gain while making the sharer dispensable. Draft-KV instead sends the key-value states formed while the sharer drafts an answer to the current question. Linear projections place these states in a side memory read through a gated attention branch, and progressive training moves from message reconstruction to answer supervision under a guard on harm from mismatched messages. Both models remain frozen and the interface trains 1.05M parameters, 348x fewer than C2C. With a Qwen3-8B sharer, a frozen Qwen2.5-0.5B-Instruct receiver reaches 78.04% on MMLU-Redux, versus 37.45% alone and 36.40% with reassigned messages. At fixed interface size, scaling the sharer from 0.6B to 8B raises accuracy from 46.11% to 78.04%; communication also transfers to held-out tasks and can exceed both models when each holds different evidence.

**一句话**：论文提出 Draft-KV，把强模型生成答案时形成的 KV 状态经线性投影送入冻结弱模型的侧记忆并用门控注意力分支读取，以极小参数训练模型间潜在通信接口，同时揭示"接收方准确率提升"并不等于真的使用了传递内容。

痛点：潜在通信（latent communication）中接收方准确率更高并不能证明它用了消息内容——把消息替换成无关问题的消息后准确率变化不到 0.60 分。方法：Draft-KV 直接发送共享模型草拟答案时产生的 KV 状态，用线性投影放入侧记忆、经门控注意力分支读取，并以渐进式训练（先重构消息、后答案监督）加上"错配消息危害"约束；两个模型保持冻结，仅训 1.05M 参数（比 C2C 少 348 倍）。结果：Qwen3-8B sharer + 冻结 Qwen2.5-0.5B-Instruct receiver 在 MMLU-Redux 达 78.04%（单独 37.45%、错配消息 36.40%），固定接口规模下把 sharer 从 0.6B 扩到 8B 使准确率从 46.11% 升到 78.04%，且可迁移到留出任务，在双方掌握不同证据时甚至超过两个模型各自的表现。

> 🔗 **与课题**：主要支撑③能力迁移与⑦评测。③：这是一项 LLM 间潜在状态/能力迁移的实证研究——强模型作 source、冻结弱模型作 target、只训一个 1.05M 的接口，并验证迁移能泛化到 held-out 任务，属于"源域→目标域知识迁移"的机制性工作，可类比课题中"工作流知识从 GEE 源域迁移到 QGIS 目标域"的迁移路径与冻结主干+轻量适配器的范式。⑦：最直接的价值在评测方法论——作者用"把消息换成无关问题的消息"做对照，证明接收方的准确率增益可能来自接口/格式而非消息内容本身，这正是课题"迁移保持率（transfer retention）"度量所需要的控制实验与消融协议，可用来判定 QGIS 落地增益是否真来自迁移的工作流知识。⑥：渐进式训练（消息重构→答案监督）与错配危害约束可为训练迁移接口/对齐中间表示提供设计参考。相比之下，本文完全不涉及①GIS Task→Workflow、②工作流结构化/DAG 表示、④QGIS operator grounding、⑤processes+links 图生成。

💡 **启发**：可直接偷的具体做法：把"重分配/错配消息对照"引入课题的迁移评测——在 GEE→QGIS 迁移中，用不相关任务的状态/表示替换迁移来的工作流知识，检验下游 QGIS 图生成增益是否真由迁移内容贡献，而非接口或格式先验。另外"先重构中间表示、再接受下游答案监督"的渐进训练顺序，可迁移到工作流中间表示与 QGIS 图生成的对齐训练。

⚠️ **局限**：潜在通信仅在同类模型与问答推理任务上验证，接收方增益强依赖 sharer 规模，且"消息内容是否被真正使用"只用无关问题替换这一种对照来判定。

### ⭐⭐⭐⭐ Do Emotion Concepts Generalize Across Sources, Modalities, and Architectures in Vision-Language Models?
**7/10** · Bohao Xing、Xin Liu、Kaishen Yuan、Deng Li、Rong Gao、Guoying Zhao · arXiv · 2026-09-28 · [原文](https://arxiv.org/abs/2609.34742v1) · [PDF](https://arxiv.org/pdf/2609.34742v1)
*入选：能力迁移*

> 📄 **摘要**：Recent studies suggest that large language models encode emotion concepts as structured internal representations, but most existing work focuses on text and a single architecture. Therefore, we ask, do emotion concepts generalize across sources, modalities, and architectures in vision--language models (VLMs)? To address this, we construct CMES (Cross-Modal Emotion Stimuli), a multi-source collection of emotion-conditioned stories, real facial expressions, synthetic portraits, and synthetic emotion-evoking scenes. For each stimulus source, we extract a separate set of six Ekman emotion vectors from each of three VLMs. We report four main findings as follows: 1) Image-derived emotion vectors form a low-dimensional geometry similar to that of text-derived vectors. Valence is relatively stable across sources, while arousal varies more. 2) Text- and image-derived emotion vectors have modest cosine similarity but still show held-out cross-modal correspondence. Text-derived vectors can also steer image interpretation. 3) Cross-architecture correspondence remains even when native cosine is near zero. *入选：能力迁移*

> 📄 **摘要**：Multi-agent systems bring together language model agents with different roles to propose, review, and refine solutions. Each agent's response depends on its model's capabilities, the reasoning strategy defined by its system prompt, and the information in its input context. Existing frameworks often adapt communication by changing this context while leaving individual prompts fixed, even when a problem calls for different skills. We study whether agents' initial responses can identify a strategy better suited to the current problem and guide its transfer to other agents. To address this, we introduce SAGE (Self-Adapting Group of Experts), a training-free framework that uses answer agreement, prefix consistency, and reciprocal peer review to select a strategy donor. SAGE transfers the selected donor's reasoning strategy to the other agents while preserving their original roles. This transfer uses only the agents' original system prompts, without access to the problem or generated solutions. After strategy adaptation, agents exchange responses through a dynamic, sparse directed acyclic graph that routes information from higher-scoring agents to lower-scoring agents. Experiments across multiple agent backbones and reasoning benchmarks show that SAGE achieves higher average accuracy than the evaluated baselines. Our code is available at https://github.com/atifquamar07/sage.

⚠️ **局限**：迁移仅限同任务内智能体间的提示级策略传播，缺乏跨域/跨工具能力迁移与结构化工作流生成的验证，DAG 是通信拓扑而非可执行流程依赖图。

### ⭐⭐⭐⭐ Shockingly Simple Self-retrospection Improves Agentic Models Without RL
**7/10** · Jonathan Light、Christopher Zhang Cui、Jeonghye Kim、Roger Creus Castanyer、Emiliano Penaloza、Zhengyan Shi · arXiv · 2026-09-28 · [原文](https://arxiv.org/abs/2609.35741v1) · [PDF](https://arxiv.org/pdf/2609.35741v1)
*入选：RL×LLM方法*

> 📄 **摘要**：People learn not only by repeating successful actions, but also by recounting and explaining their experiences, revising their understanding to guide future behavior. Can a language-model agent improve its future actions by training only on explanations of its own experience? We investigate this question by studying Retrospection-Only Fine-Tuning (ROFT), a minimal online procedure designed to isolate the effect of explanation-only training on subsequent behavior. The agent attempts a task, observes available feedback, generates a retrospective explanation, and is fine-tuned with a next-token prediction loss on the explanation tokens alone. The procedure uses neither an external teacher nor a reward-based policy update. On held-out SWE-bench Verified and Pro, it reaches 49.2% and 26.8% solve rates after 20 updates without using a verifier, compared with GRPO's 48.0% and 25.3% after 40 updates in the evaluated runs, and makes faster early progress in training time and sampled attempts. Behavioral analyses find that ROFT indirectly assigns credit to actions, encouraging good actions and discouraging incorrect ones. Moreover, prompting retrospections to emphasize more direct solutions yields shorter subsequent attempts even without an explicit length penalty. Together, these findings show that learning to explain can also improve learning to do, establishing self-generated retrospections as useful training targets and motivating further study of explanation-to-action transfer.

**一句话**：提出 Retrospection-Only Fine-Tuning (ROFT)，让语言模型智能体只对自身经历的回顾性解释做下一词预测微调，从而在没有外部教师和 RL 奖励的情况下提升后续任务表现。

> 🔗 **与课题**：主要支撑环节⑥（训练/后训练）：ROFT 是一种不含 RL 的自监督式 SFT/在线微调协议，直接对应课题的 DAPT/SFT/后训练实现手段，可作为在 GEE→QGIS 工作流推理数据上做无 verifier 自我改进的候选训练范式。次要支撑环节⑦（评测）：论文用 SWE-bench Verified/Pro、无 verifier 下的 solve rate、早期进度与采样代价做对比，并提供"哪些行为被强化/抑制"的行为分析，可作为迁移保持率与错误分析式评测的写法参考。与①（工作流推理）、③（跨平台能力迁移）、④（QGIS operator grounding）无直接关联：它的任务域是代码/软件工程智能体，未涉及工作流分解、结构化图生成或跨工具迁移。

💡 **启发**：可把"只训练自己生成的回顾解释"搬到 GIS 工作流场景：让模型在 GEE 上跑完一次 workflow 后写任务分解/依赖组织的自省文本，仅对该文本做 NTP 微调，用零 verifier 方式把 GEE 工作流经验内化为可迁移的 workflow 知识。另外"训练目标只保留解释 token、丢弃轨迹 token"这一极简设计可直接复用，避免对 QGIS 图结构做脆弱的 reward 设计。

⚠️ **局限**：实验仅限 Qwen3.5-4B 与 SWE-bench 代码任务、规模小（20 次更新），无 verifier 的自我回顾训练容易放大模型自身偏见，能否在结构化图生成这类强约束、可执行性硬验证的 QGIS 任务上成立仍需验证。

### ⭐⭐⭐⭐ SkillRubric: Co-Evolving Actor Guidance and Evaluator Rubrics for Multimodal Agents

> 📄 **摘要**：Recent work incorporates reusable skills distilled from past interactions into multimodal agent training, providing procedural guidance for long-horizon planning and tool use. > 📄 **摘要**：Large language model (LLM) agents are evolving from tool-calling systems that execute isolated instructions into task-oriented agents that pursue user goals through sustained, multi-step interactions. ### ⭐⭐⭐ ARISE: Adapting to Evolving Capability Gaps in Agentic Reinforcement Learning
**6/10** · Kun Feng、Yuchen Fang、Yiyang Tan、Shuqi Gu、Yongxiang Zhao、Yu Liu · arXiv · 2026-09-28 · [原文](https://arxiv.org/abs/2609.35532v1) · [PDF](https://arxiv.org/pdf/2609.35532v1)

> 📄 **摘要**：As a long-horizon agent improves through experience, previously observed weaknesses may recede while new limitations emerge, continually changing what it still needs to learn.
