### ⭐⭐⭐⭐ GIS-MAS: derived spatial data, query sets, evaluation artefacts and code for a spatial-reasoning-enhanced collaborative multi-agent framework
**7/10** · Qili Pan、Zixuan Mei、Yuhua Chen · Zenodo (CERN European Organization for Nuclear Research) · 2026-09-26 · [原文](https://doi.org/10.5281/zenodo.22970767)
*入选：领域×任务*

> 📄 **摘要**：## Contents - `gis_mas/`, `experiments/`, `core/`, `operators/`, `run_*.py`, `config.py`, `requirements.txt`, `.env.example` - the implementation and every evaluation script cited in the paper. The entry point for the full evaluation is `experiments/eval/run_all.py`; the end-to-end truth tier is module O and must be invoked explicitly. - `gis_mas/data/geo_knowledge.json` - the 672-entry knowledge base (403 entities + 216 spatial relations + 53 operator documents), per-entry sources retained. - `data/*.geojson`, `data/rcc8_composition.json`, `data/reference/rcc8/`, `data/templates/*.yaml` - derived spatial layers (ODbL 1.0, (c) OpenStreetMap contributors, attribution retained), the audited RCC-8 composition table with its provenance block, and the 19 task templates. - `data/*.json` - the query sets: 227 evaluation queries, the 102-item synthetic benchmark, the 24 service-area expansion queries, and the held-out slice definition. - `output/eval_results/`, `output/ablation/` - the per-item evaluation artefacts cited in the paper (the evidence record), plus the blind annotation sheets and the machine/human annotation readings. - `MANIFEST_SHA256.txt` - SHA256 and size of every file in this deposit. ## Deliberately NOT included - **Amap-derived data** (POI snapshot, geocoding results, driving-distance truth): the Amap Open Platform terms of service do not permit redistribution. These files are reproducible only by re-collecting with the reader's own API key; the statistical scope and grid parameters are given in the paper (Table 1). - **OpenStreetMap extracts** (`.gpkg`, `.osm.pbf`) and derived road-network graphs (`.pkl`): hundreds of MB, ODbL-encumbered, and rebuildable with the scripts in `experiments/build_*.py`. - **Model caches and third-party binaries** (embedding models, GraphHopper jar) and **build products** (rendered PNGs, logs). ## Licences This deposit is released under **CC BY 4.0** (the record licence), with two stated exceptions that keep upstream terms intact: - **Code** (`gis_mas/`, `experiments/`, `run_*.py`, `core/`, `operators/`): **MIT** (see `LICENSE`). - **OpenStreetMap-derived spatial layers** (`data/*.geojson`): **ODbL 1.0**, (c) OpenStreetMap contributors. - Wikidata-derived attributes: CC0. ## Reproduction Install `requirements.txt` in a Python 3.13 environment, copy `.env.example` to `.env` and add your own Amap and DashScope keys, then run `python experiments/eval/run_all.py` (about 40-60 minutes; module O runs separately). Service-area and network-distance steps need GraphHopper and a JDK; without them those steps degrade explicitly and say so in the answer. `output/eval_results/data_hashes.json` records the SHA256 of the shipped artefacts and can be regenerated with `python experiments/data_hashes.py`.

**一句话**：发布 GIS-MAS（空间推理增强的协作多智能体框架）的派生空间数据、查询集、评测产物与代码的 Zenodo 数据/代码归档。

痛点在于 GIS 空间推理任务缺少可复现的数据、评测查询与标注产物，作者以归档形式一次性开放实现与全部评测脚本。方法侧包含 gis_mas/、core/、operators/ 等模块，内置 672 条地理知识库（403 实体 + 216 空间关系 + 53 算子文档）、RCC-8 复合表、19 个任务模板以及 227 条评测查询与 102 条合成基准。结果层面提供 per-item 评测记录（output/eval_results/、output/ablation/）以及机器/人工标注对照，端到端真值层由模块 O 显式调用，Cheb 因高德 ToS 未随附。

> 🔗 **与课题**：与 M1 的知识图谱约束解码相关：geo_knowledge.json 的实体—空间关系—算子文档三层结构可作为 L3 算子语义层与 KG 约束的来源；RCC-8 复合表与迁移合法性矩阵在形式上同构，可借其校验空间关系推理的转移合法性。与 eval 模块相关：227 条评测查询、102 条合成基准、19 个任务模板与 held-out 划分可直接用于 L3 规划评测与 L3→QGIS landing 的对照。与 baseline 相关：GIS-MAS 多智能体协作框架可作为 M1/M2/M3 之外的多智能体基线进行比较。与 data 相关：其盲标注表 + 人工/机器标注读数的双轨设计，可借鉴到最终工作流人工可用率层。

💡 **启发**：把算子文档、空间关系、实体拆成带来源的知识库条目并配 RCC-8 复合表做关系闭包校验——可直接迁移为 M1 的 KG 约束解码资源；其盲标注 + 人工/机器双读数的评测协议可复用到 landing 层的人工可用率评估。

⚠️ **局限**：这是数据/代码归档而非完整方法论文，核心模型细节与自动生成能力需配合其正文才能判断；且高德派生数据未随附，复现部分评测需自备 API key。
