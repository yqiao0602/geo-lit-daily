### 🔥 ⭐⭐⭐⭐ HGM-Dual: Lineage-Aware Guided Agent Harness Optimization for Long-Horizon Planning
**8/10** · Sudipta Paul、Pengrui Quan、Aounon Kumar、Nicholas Tzou、Vivek Kulkarni、Srinivas Chappidi · arXiv · 2026-10-21 · [原文](https://arxiv.org/abs/2610.30042v1) · [PDF](https://arxiv.org/pdf/2610.30042v1)
*入选：工作流×工具推理*

> 📄 **摘要**：Harness optimization, which improves an agent's prompts, tools, and workflows, is an increasingly effective way to enhance agents built on frozen or closed-source LLMs. Leading approaches such as the Darwin--Godel Machine and the Huxley--Godel Machine (HGM) rely on recursive self-improvement and were developed mainly for coding, where the competence needed to improve the agent coincides with the competence being improved. Planning tasks, in which an agent must produce a sequence of tool calls that jointly satisfies interacting constraints, break this alignment. There, open-ended self-modification repeatedly explores ineffective changes and consumes substantial evaluation budgets. We introduce HGM-Dual, a diagnostic-guided framework for budget-efficient harness evolution for planning agents. First, HGM-Dual represents agent evolution as lineage-aware context. This context records what each ancestor changed, which behaviors improved or regressed, and which modifications were ineffective, giving the editor explicit edit-outcome attribution instead of an unstructured archive of past agents. Second, HGM-Dual introduces error-conditioned dual-path child generation. For each selected parent, it generates a general child that preserves open-ended exploration and specialized children that target the harness components most likely responsible for the parent's highest-ranked constraint violations. HGM-Dual outperforms the strongest baseline by up to 14.45% relative improvement in case accuracy while matching HGM variants' final performance with 2x-4x fewer evaluation budget.

**一句话**：提出 HGM-Dual，用血缘感知上下文与错误条件双路径子代生成，对冻结/闭源 LLM 上的规划智能体做预算高效的 harness（提示/工具/工作流）进化优化。

痛点：以往基于递归自改进的 harness 优化（Darwin/Huxley–Gödel Machine）主要针对编码任务，而在需要产出满足多重交互约束的工具调用序列的规划任务中，自修改会盲目探索无效改动、大量消耗评估预算。方法：把智能体进化表示为血缘感知上下文（记录每个祖先改了什么、哪些行为提升/回退、哪些修改无效），并引入错误条件双路径子代生成——通用子代保持开放式探索，专门子代针对父代排名最高的约束违反所对应的 harness 组件。结果：相对最强基线最高取得 14.45% 的相对提升。

> 🔗 **与课题**：①最直接：论文把“长时程规划=产出满足交互约束的工具调用序列”作为核心问题，正是工作流推理/任务分解的研究对象；⑤它生成的输出是受约束的工具调用序列（可视为节点+依赖的图结构），与 processes+links 依赖闭合的结构化生成同构；⑦其“按约束违反排名定位失败组件”的诊断协议可直接映射到幻觉算子率、依赖不闭合率、执行成功率的错误分析；⑥它证明了在冻结/闭源模型上以 harness 搜索替代梯度训练可以改进规划能力，属于我们训练/后训练环节之外的对照路线；③较弱，仅涉及同一 agent 内部的跨组件改动，不含跨域/跨平台迁移实证，故不能充当迁移保持率的证据。

💡 **启发**：把“约束违反排名”作为诊断信号驱动迭代改进：把 QGIS 落地失败（幻觉算子、依赖未闭合、执行报错）按违反频次排名，定位到具体的 prompt/工具描述/流程模板组件再定向修复；同时可把血缘式“编辑—结果归因”记忆表做成工作流修复的反思记忆，避免重复无效修改。

⚠️ **局限**：进化式搜索仍依赖较大评估预算且实验限于规划类基准，未验证改动收益能否迁移到新工具域/新平台（如 GEE→QGIS），也未报告迁移保持率。

🚨 **为什么必须重视**：该文把“满足交互约束的工具调用序列生成”当作核心科学问题，并给出可复用的诊断—归因优化协议，与我们的结构化 QGIS 图生成与评测环节正面撞车。其“免训练、靠 harness 进化提升规划能力”的路线若成立，会直接挑战我们以 SFT/DAPT 为主轴的实现路径，需尽快确认其适用边界。诊断式反馈协议本身可直接改造为我们的评测与修复基线。

### ⭐⭐⭐ Agentic Music Post-Production
**6/10** · Jaywon Koo、Junghyun Koo、Marco A. Martinez-Ramirez、Wei-Hsiang Liao、Seungheon Doh、Qiyu Wu · arXiv · 2026-10-21 · [原文](https://arxiv.org/abs/2610.29093v1) · [PDF](https://arxiv.org/pdf/2610.29093v1)
*入选：RL×LLM方法*

> 📄 **摘要**：We introduce MixAgent, an agentic pipeline for music post-production that follows the workflow of audio engineers to build interpretable and editable mixing plans guided by a reference song. A grouping agent first routes related input tracks, such as drum recordings, into subgroups. A planning agent then uses retrieved examples to choose and order audio effects, such as volume control and reverb, for tracks, subgroups, and the full mix. To refine the mix, a detector identifies what needs correction, and a critic proposes numerical parameter adjustments from tracks to the full mix. In our experiments, prompting recent multimodal models to listen and revise often worsens the mix, making reliable correction a central challenge. We therefore build MixCritic, a dataset of 45,657 repair critiques derived from parameters fitted to professional mixes, and train the critic with supervised fine-tuning followed by preference optimization on rendered audio outcomes. On MedleyDB, learned refinement reduces error by 19% relative to the initial mix, with preference optimization reducing it by 8.4% over supervised training alone. Retrieved examples further improve effects selection, and a human listening test shows that MixAgent gets higher quality ratings than mixes produced by Qwen3-Omni, Gemini 3.8 Flash and GPT-4o-audio.

**一句话**：提出 MixAgent——一条模仿录音工程师工作流的音乐后期制作 agent 流水线：分组 agent 归并音轨，规划 agent 检索示例后为各轨和整体混音选择并排序音频效果，检测器与批评器给出数值参数修正，并构建 MixCritic 数据集用 SFT+偏好优化训练批评器。

痛点：直接用多模态大模型提示生成或反复修改混音往往越改越差，可靠的参数级“纠错”成为核心难题。方法：把后期制作拆成可解释、可编辑的分组—规划（效果选择与排序）—检测—批评四段式 agent 流程，并把专业混音参数拟合结果转化为 45657 条修复批评数据训练批评器（SFT 后再做偏好优化）。结果：在 MedleyDB 上学习式精修使误差较初始混音降低 19%，偏好优化在 SFT 基础上再降 8.4%，检索示例改善效果选择，人听测试优于 Qwen3-Omni、Gemini 3.8 Flash 与 GPT-4o-audio。

> 🔗 **与课题**：支撑环节①与⑤的弱相关变体：规划 agent“为各对象选择并排序效果器链”本质是面向算子的步骤规划与顺序依赖组织（类似 processes+links 的扁平版），且强调计划可解释、可编辑，与结构化图生成思想同构；环节⑥：批评器用 SFT+偏好优化从渲染结果反推数值参数修正，属于“生成—执行—反馈修正”的训练范式；环节⑦：以误差下降率与人评作为计划质量度量。但全文没有跨平台/跨域迁移实验（无 GEE→QGIS、tool→tool 的保持率研究），也没有对工作流推理能力本身做基准化，因此仅是通用方法层面的支撑，达不到 8 分。

💡 **启发**：可借鉴“分组 agent（对象聚合）→ 规划 agent（算子选择与排序）→ 检测器定位缺陷 → 批评器输出数值修正”的四段结构与“计划可编辑”的设计；另外用专业成品反推参数、自动合成大规模修复批评数据来训练批评/纠错模型，可直接迁移为 QGIS 图生成的幻觉算子与依赖错误的自动修复数据构造方案。

⚠️ **局限**：属音乐领域的系统级应用论文，规划能力来自提示与检索而非对模型内部工作流知识的刻画，且效果高度依赖专用音频特征，迁移结论需谨慎。

**▸ 建议：引用**

### 🔥 ⭐⭐⭐⭐ Harness Scaling for Generalizable Agentic Reinforcement Learning
**8/10** · Fei Bai、Huatong Song、Chuan Hao、Ran Tao、Jian Yang、Bryan Dai · arXiv · 2026-10-21 · [原文](https://arxiv.org/abs/2610.29458v1) · [PDF](https://arxiv.org/pdf/2610.29458v1)
*入选：RL×LLM方法*

> 📄 **摘要**：Agent harnesses have become a central component of modern agentic systems, shaping how models use tools, manage context, and coordinate long-horizon interaction. Realizing the benefits of these harnesses depends on how effectively the underlying model can make use of them, motivating reinforcement learning directly through the harness. However, existing approaches typically train through a single fixed harness, which can lead to specialization and limited transfer across harness configurations. To address this, we introduce \textbf{Harness Scaling}, a new scaling dimension for agentic RL that extends training from a single harness to diverse execution configurations. Concretely, we construct a factorized harness space, select a compact training subset with balanced factorial coverage, and organize cross-harness training to combine global coverage with controlled variation for the same task. Across multiple benchmarks, model scales, and RL algorithms, Harness Scaling consistently improves generalization to unseen white-box configurations. Moreover, models trained through structured white-box variation transfer effectively to unseen external black-box harnesses, outperforming models trained through a single complex black-box harness. These results establish harness diversity as a meaningful scaling dimension for agentic RL and highlight the importance of how this diversity is organized for cross-harness generalization.

**一句话**：提出 Harness Scaling：把 agentic RL 训练从单一 harness 扩展到因子化设计的多 harness 执行配置空间，以提升跨 harness 的泛化与迁移。

痛点：现有 agentic RL 通常只在单一固定 harness（工具接口、上下文管理、长程交互组织方式）上训练，模型容易对特定配置特化、难以迁移到其他执行配置。方法：构造因子化 harness 空间，按平衡因子覆盖挑选紧凑训练子集，并组织跨 harness 训练——全局覆盖＋同任务受控变化。结果：在多个基准、模型规模与 RL 算法上，对未见白盒配置的泛化稳定提升，且结构化白盒变化训练的模型能有效迁移到未见的外部黑盒 harness，优于用单一复杂黑盒 harness 训练。

> 🔗 **与课题**：主要支撑环节③（跨域/跨平台能力迁移）与⑥（训练/后训练），并与⑦（评测协议）相关。逐环节对照：(1) ③——论文的核心命题是“在某一执行配置（harness）上训练得到的 agentic 能力能否迁移到未见配置”，这与本课题“GEE 工作流上学到的推理能力迁移到 QGIS operator grounding”在结构上同构：harness 相当于工具接口与执行环境的抽象，跨 harness 迁移即跨平台/跨工具迁移。(2) ⑥——它给出了可操作的训练设计：把执行环境因子化、按平衡因子覆盖采样训练子集、同任务多配置受控变化，这正对应本课题 GEE/QGIS 双平台训练集的构造方式（平台 × 算子族 × 图结构复杂度）。(3) ⑦——其“未见白盒 + 未见外部黑盒”的双层留出评测，可直接改写为迁移保持率（transfer retention）与 QGIS 落地可用率的评测协议。(4) 反面对照价值：论文证明“单一固定 harness 训练 → 特化、迁移受限”，这为本课题“只在 GEE 上训练会损害 QGIS grounding”的假设提供了直接实验依据与 baseline 设定。(5) 需注意它并未触及环节①②⑤：不涉及工作流分解、显式结构化/DAG 依赖表示、processes+links 图生成，因此只能作为迁移机制与训练/评测协议层的外部支撑，而非核心方法来源。

💡 **启发**：可偷两点：一是把“平台（GEE/QGIS）× 算子族 × 工作流结构复杂度”做因子化并平衡采样，构造紧凑但有覆盖度的跨平台训练子集；二是“同任务多 harness 受控变化”的评测设计，可直接改造成迁移保持率指标（同一 GIS 任务在两平台上的结构与执行一致率）。

⚠️ **局限**：harness 多样性作用于交互脚手架层面（工具定义、上下文管理、交互循环），论文未证明迁移发生在工作流语义知识层面，且基准为通用 agentic 任务而非 GIS 工作流，引用时需说明其迁移层级与本课题的差异。

🚨 **为什么必须重视**：它把“跨执行配置/工具接口的能力迁移”正式确立为一个可训练的 scaling 维度，与本课题 GEE→QGIS 迁移是同一科学问题在不同载体上的实例，属于直接竞品框架，必须纳入对比。其“单 harness 训练导致特化、跨配置多样性训练带来未见配置泛化”的结论，直接决定我们训练集是否需要平台混合而非仅 GEE。其因子化配置空间与双层留出评测协议可立即借用，作为跨平台迁移的 baseline 与指标定义。

*入选：工作流×工具推理*

> 📄 **摘要**：Designing effective multi-agent systems (MAS) remains a challenging and resource-intensive task. We propose a Bayesian Evolutionary Optimization framework for automatically discovering task-specific MAS topologies. The approach combines evolutionary operators to generate diverse workflow graphs with Bayesian optimization to focus cost intensive evaluations on promising candidates. In contrast to LLM-based candidate selection, our approach uses a graph-aware Gaussian Process and Expected Improvement to provide an explicit selection criterion during evolutionary search. We evaluate the method on BigCodeBench for code generation and on a tabular preprocessing benchmark using TabPFN. **一句话**：用贝叶斯进化优化自动搜索多智能体系统的工作流拓扑结构。

⚠️ **局限**：优化对象是智能体拓扑而非模型内部可迁移的工作流知识，且评估限于代码生成与表格预处理，与 GIS/QGIS 算子落地相距较远。

## 🤖 GIS Agent 与工具使用（2 篇）

### ⭐⭐⭐ Steering Black-Box Large Language Model Agents with Pitfall Anticipation World Model
**6/10** · Jiongxiao Wang、Han Ding、Youzhi Luo、Yawei Wang、Yun Zhou、Linbo Liu · arXiv · 2026-10-21 · [原文](https://arxiv.org/abs/2610.29139v1) · [PDF](https://arxiv.org/pdf/2610.29139v1)
*入选：RL×LLM方法*

> 📄 **摘要**：Frontier black-box Large Language Model (LLM) agents are proficient at long-horizon reasoning and precise action generation. However, when it comes to a specific agentic task, they have no internalized knowledge of how that particular environment unfolds. A world model offers a natural remedy, providing the agent with environment specific knowledge by foreseeing how the environment will respond to the action it is about to take. Prior world models for LLM agents mainly predict next observations at each step, which is costly and often uninformative because individual observations provide limited task-relevant guidance and not every step requires call for foresight. This raises a key question: what a world model should predict and when should it be invoked for agentic tasks? Our pilot study suggests that world model guidance is most useful when it anticipates pitfalls within a bounded multi-step future. Motivated by this, we introduce Pitfall Anticipation World Model (PAWM), which selectively intervenes when a potential pitfall arises and predicts the impending failure to steer the agent away from it. PAWM is trained in two stages: Supervised Fine-Tuning (SFT) on synthetic data labeled with agent pitfalls, followed by GRPO co-training with a black-box LLM to further optimize it in the target environment. PAWM improves Claude Sonnet 4.5 performance by 24.3% on ScienceWorld and 7.7% on WebArena-Lite, outperforming a range of baselines. These results demonstrate that PAWM provides an effective form of world model guidance for black-box LLM agents.

**一句话**：提出 Pitfall Anticipation World Model（PAWM）：它预测智能体在未来若干步内可能遇到的陷阱，并在必要时介入，通过 SFT + GRPO 协同训练，引导黑盒 LLM 智能体避免失败。

痛点在于：黑盒 LLM 智能体虽擅长长程推理，但对具体任务环境缺乏内化知识；而逐步预测下一观测的世界模型成本高且信息量低。作者通过初步研究发现，世界模型最有价值的用法是在有界多步窗口内预判即将发生的失败，据此提出 PAWM：只在潜在陷阱出现时选择性介入，分两阶段训练（用合成陷阱标注数据做 SFT，再与黑盒 LLM 做 GRPO 协同训练）。在 ScienceWorld 上使 Claude Sonnet 4.5 提升 24.3%，在 WebArena-Lite 上提升 7.7%。

### ⭐⭐⭐ Keeping Time vs. Understanding Time: Neither Alone Explains Temporal Reasoning in LLMs
**6/10** · Auss Abbood、Fernando Martínez-Plumed、José Hernández-Orallo、Nigel Collier · arXiv · 2026-10-21 · [原文](https://arxiv.org/abs/2610.29507v1) · [PDF](https://arxiv.org/pdf/2610.29507v1)
*入选：能力迁移*

> 📄 **摘要**：Temporal reasoning is widely assumed to decompose into two modes: temporal arithmetic (date and time calculations), and temporal semantics (understanding temporal and causal relations). This dichotomy shapes how benchmarks are designed, how models are trained, and how progress is measured, yet its empirical validity has never been directly tested. We provide two lines of evidence that challenge it. First, we test whether tasks labelled as arithmetic or semantic by the benchmarks support transferable gains within their purported mode. Finetuning on these subsets yields predominantly dataset-specific gains ($+6.8$ to $+23.1$ percentage points), while transfer to a different dataset in the same mode ranges from $-3.2$ to $+1.1$ percentage points. Across the two benchmark families used in the transfer analysis, this pattern provides little evidence of coherent, transferable temporal abilities. Second, using cognitive-demand-based model evaluation, we examine which capabilities actually drive performance on these benchmarks. We find that quantitative and logical reasoning, the assumed proxies for temporal arithmetic and temporal semantics, are not the primary drivers; knowledge is. Together, these findings show that current temporal reasoning benchmarks do not cleanly realise the arithmetic-semantics distinction and instead largely reward models for remembering how time typically works.

**一句话**：论文直接检验了LLM时间推理中“算术与语义”二分假设是否成立，发现微调收益高度依赖具体数据集、同模式跨数据集迁移几乎为零，且真正驱动性能的是知识而非推理能力。

痛点：时间推理被普遍假设可分解为时间算术与时间语义两种模式，但这一二分从未被直接验证。方法：在两个基准族上分别对“算术”和“语义”子集做微调，测量同模式内的跨数据集迁移增益，并用认知需求式评估对性能驱动因素做归因分析。结果：微调在本数据集上带来 +6.8~+23.1 个百分点的提升，但迁移到同模式的另一数据集仅 -3.2~+1.1 个百分点；定量与逻辑推理并非主要驱动因素，知识才是主导，现有基准主要在奖励模型“记住时间通常如何运作”。

> 🔗 **与课题**：主要支撑⑦评测：提供“子集微调→同域增益 vs 跨域增益”的迁移增益/保持率测量协议，以及基准效度质疑与能力归因评估思路；弱关联③：其迁移分析是跨数据集的同能力模式迁移实证，而非跨工具/跨平台/源域→目标域的迁移，可作为迁移测量方法学参考而非迁移结论依据；与①④⑤⑥无直接关系。

💡 **启发**：可借用其“同模式内微调→同数据集增益 vs 换数据集增益”的对照设计，量化 GEE 上训练后 QGIS 侧的迁移保持率；并用“知识 vs 推理”归因思路区分模型是学到可迁移的工作流知识，还是记住 GEE 数据集表层模式。

⚠️ **局限**：结论局限于时间推理基准上的两模式二分，微调规模与基准数量有限，不能直接外推为能力迁移机制的一般性结论。

### ⭐⭐⭐ ARCANA: A Benchmark for Abstraction and Analogical Reasoning
**6/10** · Ruqi Chen、Zilei Wang、Wei Wang · arXiv · 2026-10-21 · [原文](https://arxiv.org/abs/2610.29271v1) · [PDF](https://arxiv.org/pdf/2610.29271v1)
*入选：领域×任务*

> 📄 **摘要**：Analogical reasoning is widely considered a fundamental component of human intelligence. Few benchmarks are designed to explicitly test far analogical reasoning - reasoning between domains that are superficially dissimilar yet share deep relational or structural similarities. In this work, we introduce an analogical reasoning benchmark called Abstraction and Reasoning Corpus of ANAlogy (ARCANA). The tasks of ARCANA require performing far analogical mappings from real-world objects or physical phenomena to abstract grid-based transformations, different from the well-known ARC-AGI benchmark which primarily emphasized innate human priors. We validate ARCANA through a human study, demonstrating that humans solve these tasks reliably. In contrast, evaluations across a range of large language models show a distinct performance gap compared to humans, revealing systematic failure modes that remain challenging for current models. To address this gap, we propose ConceptSIR, a reasoning framework based on concept slippage, introspection, and reflection. Experiments demonstrate that ConceptSIR enables standard LLMs to solve several challenging ARCANA tasks that were unsolved by direct prompting in our evaluation. Overall, our results suggest that far analogical reasoning remains an open problem for contemporary LLMs. All the materials are available at sites.google.com/view/arcanacogtest. The complete codebase, including benchmark, and ConceptSIR, is publicly available at https://github.com/density-11/arcana-test. All ARCANA data and task instances can be accessed and explored at https://arcanacogtest.org/.

**一句话**：论文构建了 ARCANA 基准，用从真实世界物体/物理现象到抽象网格变换的远类比映射任务，检验 LLM 的抽象与类比推理能力，并提出 ConceptSIR 反思式推理框架。

痛点：现有基准（如 ARC-AGI）主要考察人类先天先验，缺乏对'表层不相似但深层关系/结构相似'的远类比推理的显式测试。方法：作者构建 ARCANA 基准（真实世界对象/现象→抽象网格变换的映射任务），做人类被试验证，并系统评测多种 LLM，另提出基于概念滑移、内省与反思的 ConceptSIR 推理框架。结果：人类可稳定求解，LLM 存在明显性能鸿沟与系统性失败模式，ConceptSIR 能解决部分直接提示失败的难题，说明远类比推理对当代 LLM 仍是开放问题。

> 🔗 **与课题**：主要支撑⑦评测：提供了一个'人类可靠、模型系统性失败'的诊断型基准范式与失败模式分析框架，可用于设计迁移保持率（transfer retention）评测——即在表层算子名/平台改变后模型是否仍保持深层工作流结构。弱支撑③能力迁移：其'表层不相似、深层关系同构'的远类比设定，在认知层面同构于 GEE workflow→QGIS operator 的源域→目标域结构保持问题，可借其任务构造思路做'结构同构、表面不同'的迁移探针。亦与①有边缘关联：ConceptSIR 的概念滑移+内省+反思循环属于推理过程的显式化干预，可作为 workflow reasoning 的测试时策略参考。但任务形态是网格谜题，不涉及 tool/operator grounding、代码/API 或可执行图生成，故不达高相关档。

💡 **启发**：可借鉴'表层不相似、深层同构'的任务构造法：保持 workflow 的 DAG 依赖结构不变、只替换算子表面形式（GEE 函数名→QGIS process id），做成类比迁移探针来量化 transfer retention；ConceptSIR 的'概念滑移—内省—反思'多轮自我校正循环可移植为 grounding 失败后的算子自纠错环节。

⚠️ **局限**：任务是抽象网格变换谜题，无工具调用、无执行验证、无真实 API 接地，与可执行 QGIS 图生成之间存在较大语义距离，引用时只能作认知/评测层面的类比依据。

### ⭐⭐ Preference Is Not Permission: Personalizing the Auto-Purchase Line in Agentic Commerce
**5/10** · Ryotaro Shimizu、Sai HtaungKham、Mo Fan · arXiv · 2026-10-21 · [原文](https://arxiv.org/abs/2610.29216v1) · [PDF](https://arxiv.org/pdf/2610.29216v1)
*入选：能力迁移*

> 📄 **摘要**：Personalized shopping benchmarks ask which item fits the user; we ask how far an agent may commit on that item, and pose learning the individual's auto-purchase line as a task. The boundary is evidence-conditioned and three-valued: whether committing is appropriate depends on the sufficiency of product information (warrant), reversibility, price against the user's norm, and urgency, not only on fit; and the natural output is don't buy, confirm first, or buy automatically. Across sixteen instruction-tuned models, autonomous commitment is misaligned with a human authorization reference in which fifteen annotators, role-playing the delegating principal from a given profile, choose the furthest action they would allow without confirmation: models commit even when fit is low and when their own evidence flag reports the warrant missing. This is overreach. The line is individual: these raters disagree, yet the disagreement is structured and partly predictable from a person's own other labels. A shallow learner on a few dozen of a person's own labels predicts their held-out auto-purchase line at a median of 0.79 by 30-40 labels, outperforming every evaluated prompt$\times$model configuration, including a per-annotator oracle over 80 configurations; the learned boundary does not transfer across domains. We release the counterfactual benchmark, human authorization reference, and annotation protocol after acceptance.

**一句话**：提出“自动购买线”任务：让智能体判断在无需用户确认的情况下最多能自主执行到哪一步（不买/先确认/自动买），并发布反事实基准、人工授权参考与标注协议。

痛点：现有个人化购物基准只问“哪件商品符合用户”，却不问“智能体在该商品上能自主推进多远”。方法：把自动购买线定义为由证据条件决定的三值判断，判断时不仅看 fit，还看产品信息充分性（warrant）、可逆性、价格相对个人常态和紧迫性；用 15 名标注者角色扮演委托人构建人工授权参考，评测 16 个指令微调模型，并训练浅层学习器，用个人少量标签预测其边界。结果：模型普遍越权，在 fit 低、甚至自身证据标记显示 warrant 缺失时仍选择自主承诺；个人边界差异结构化、可从该用户其他标签部分预测，30–40 条个人标签即可中位 0.79 命中留出边界，超过所有 prompt×model 配置（含 80 配置的 per-annotator oracle），但学到的边界不跨域迁移。

> 🔗 **与课题**：主要支撑⑦评测：论文给出“人工授权参考 + 越权率（overreach）”式的评测协议与错误分析范式，可参照其思路把“模型是否在证据不足时仍输出算子”定义为可量化的幻觉算子率。次要涉及③能力迁移与⑥训练/适配：论文明确测量“学到的个人边界不跨域迁移”，这正是 transfer retention 问题的一种最小化实验形态；其“几十条个人标签训练的浅层学习器胜过所有 prompt×model 配置”则是轻量适配基线，可作为对比参照。但它既非工作流推理，也非 tool/operator grounding 或结构化图生成，①、②、④、⑤均无直接对应。

💡 **启发**：把三值证据条件化决策（abstain / confirm / commit）迁移到 QGIS 算子落地：只有 schema、API、参数证据（warrant）充分时才 emit process+link，否则降级为确认或弃权，可由此把“幻觉算子率”重新定义为“越过 warrant 的 overreach 率”；另可借鉴其“用极少量个人标签训练浅层预测器并与全配置 oracle 对比”的协议，为迁移保持率设计一个廉价的对照基线。

⚠️ **局限**：领域是 agentic commerce，与 GIS 工作流、工具调用落地无交集；个人边界学习器是浅层模型而非 LLM 能力迁移，“不跨域迁移”只对个性化决策边界成立，不能直接外推到 GEE→QGIS 的技能迁移结论。

### ⭐⭐⭐ CORD: Conflict-Aware Optimization for Joint RL and Distillation in Agents
**6/10** · Wenhao Yu、Zhengcheng Wang、Jiahong Liu、Zexuan Qiu、Minda Hu、Shaohang Wei · arXiv · 2026-10-21 · [原文](https://arxiv.org/abs/2610.29965v1) · [PDF](https://arxiv.org/pdf/2610.29965v1)
*入选：RL×LLM方法*

> 📄 **摘要**：Joint reinforcement learning and self-distillation combines task rewards with dense teacher guidance for agent training, but their gradients can partly cancel. A mixing coefficient controls relative scale without selectively removing opposing components. We present CORD, a general framework for conflict-aware optimization of two objectives. CORD separates the choice of protected objective from the condition that triggers projection, and combines the gradients once per optimizer mini-batch. A nearest-point formulation yields a closed-form update and characterizes its first-order effect on the protected objective before optimizer transformations. Gradient diagnostics connect conflict in agent training to lost local optimization progress and motivate selective correction. As a gradient-combination mechanism, CORD can be added to different joint training recipes while retaining their objectives. Across three such recipes, it improves ALFWorld success by 1.5-15.9 percentage points. On WebShop, it improves two of the three pairs, with SDAR rising from 60.7% to 64.6% success. Our analyses explain why protection direction and projection gate must be chosen together, and why the distillation objective and its mixing weight remain consequential after projection.

**一句话**：提出 CORD 框架，用冲突感知的梯度投影方式联合强化学习与自蒸馏目标来训练智能体，缓解两个目标梯度相互抵消的问题。

痛点：智能体训练中联合使用任务奖励(RL)与教师蒸馏时，二者的梯度部分相互抵消，而单一混合系数只能调整相对尺度，无法选择性去除相反方向的分量。方法：CORD 把被保护目标的选择与触发投影的条件区分开，在每个优化器 mini-batch 上一次性合并梯度，并用最近点闭式解刻画投影对保护目标的一阶影响。结果：在三种联合训练配方上，ALFWorld 成功率提升 1.5–15.9 个百分点，WebShop 上三组中两组提升（SDAR 60.7%→64.6%）。

> 🔗 **与课题**：主要支撑环节⑥（训练/后训练）：它提供一种通用的 RL+蒸馏联合训练时的梯度冲突消解机制，可用于“工作流推理智能体”在 DAPT/SFT 之后接 RL 微调时的稳定性改进；其次与⑦（评测）弱相关，因其给出冲突诊断指标（局部优化进度丢失）可借鉴为训练侧监控。但论文不涉及工作流推理、结构化 DAG 生成、工具/算子 grounding，也不涉及跨域迁移，因此它不是核心竞品。

⚠️ **局限**：验证仅限 ALFWorld/WebShop 文本智能体任务，未触及工具落地、结构化图生成或跨平台迁移，因此收益能否外推到 workflow/DAG 生成尚不清楚。

### ⭐⭐⭐ BIRD-RL: Scaling Agentic Reinforcement Learning over Stateful Data-Centric Environments
**6/10** · Ge Qu、Jinyang Li、Xiaohan Xu、Xiaolong Li、Bowen Qin、Nan Huo · arXiv · 2026-10-21 · [原文](https://arxiv.org/abs/2610.29426v1) · [PDF](https://arxiv.org/pdf/2610.29426v1)
*入选：RL×LLM方法*

> 📄 **摘要**：While agentic reinforcement learning (RL) has emerged as a promising paradigm for training small language models (SLMs), existing frameworks are predominantly tool-centric and struggle with data-centric environments. Specifically, applying tool-centric frameworks to stateful tasks like SQL debugging introduces severe spatial inefficiencies since proper environment isolation typically requires a separate database container per rollout. Naively reusing databases without tracking evolving states across multi-turn interactions causes trajectory contamination and cross-trajectory interference, which severely destabilizes policy updates. To overcome these bottlenecks, we introduce BIRD-RL, a novel four-stage agentic RL curriculum that alternately enhances foundational agent reasoning and trajectory-adaptive on-policy exploration to circumvent the instability inherently associated with direct end-to-end learning. Crucially, to support this curriculum, BIRD-RL is driven by a Trajectory-scoped Persistent Execution Infrastructure, which enables safe database replica reuse while preserving trajectory isolation. This design improves spatial RL efficiency by 12.8x, successfully enabling scalable agentic RL for complex data-centric tasks without needs of Kubernettes. Empirical evaluations on the BIRD-CRITIC-SQLite benchmark demonstrate that our 7B and 14B models achieve Success Rates of 44.40% and 48.00%, respectively, showing competitive performance against strong proprietary model-based agents such as Claude-Opus-4.6 Agent (48.20%). Furthermore, BIRD-RL successfully trains unified SLMs capable of both advanced SQL debugging and generation, highlighting its broader potential for multi-objective optimization across heterogeneous, real-world data-centric tasks.

**一句话**：提出 BIRD-RL——一个四阶段 agentic RL 训练课程，配合以轨迹为作用域的持久执行基础设施，用于在状态化的 SQL 调试环境中训练 7B/14B 小模型。

痛点：现有 agentic RL 框架多为 tool-centric，面对 stateful 的数据中心任务（如 SQL 调试）时，若严格隔离环境就要为每次 rollout 开独立数据库容器，空间开销极大；而朴素复用数据库又不追踪多轮状态演化，导致轨迹污染与跨轨迹干扰、策略更新不稳定。方法：设计四阶段 RL 课程，交替强化基础 agent 推理与轨迹自适应 on-policy 探索，并配套 Trajectory-scoped Persistent Execution Infrastructure，在保证轨迹隔离的前提下安全复用数据库副本。结果：空间 RL 效率提升 12.8 倍，无需 K8s，7B/14B 模型在 BIRD-CRITIC-SQLite 上成功率 44.40%/48.00%。
