### ⭐⭐⭐⭐ Second-Order Problem Solving for Recursive Self-Improvement in Formal Verification
**7/10** · Yuxuan Jiang、Aditya Vempaty、Ashish Jagmohan · arXiv · 2026-10-05 · [原文](https://arxiv.org/abs/2610.05701v1) · [PDF](https://arxiv.org/pdf/2610.05701v1)
*入选：工作流×工具推理*

> 📄 **摘要**：Recursive self-improvement (RSI) enables agents to iteratively optimize their workflows via execution feedback. However, standard RSI typically operates as a first-order optimizer: it repeatedly patches surface-level parameters in response to immediate failure symptoms, often leading to trial-and-error thrashing without resolving underlying mechanisms. To address this limitation, we introduce SO-RSI, a framework that elevates workflow optimization to a second-order diagnostic inquiry, investigating why failures occur before committing to structural interventions. SO-RSI passively monitors execution traces for three structural anomalies (recurrence, opposing edits, and expectation mismatch) to trigger targeted mechanism investigations. By executing lightweight diagnostic probes and maintaining persistent inquiry memory across RSI rounds, SO-RSI accumulates causal evidence to guide systematic workflow edits rather than parameter patches. Across Lean 4 proof generation and Verus-based verifiable code generation, SO-RSI improves final held-out pass rates over Naive RSI by 21.8 and 25.8 percentage points under matched 24-hour search budgets. Behavioral analyses further confirm that SO-RSI substantially suppresses failure recurrence and eliminates unproductive zero-progress optimization loops.

**一句话**：提出 SO-RSI，用二阶诊断式探究（监控执行轨迹中的复发、对冲编辑、期望失配三类结构异常并做机制级探针）替代一阶参数式试错，来驱动 agent 工作流的结构化自我改进。

痛点：标准递归自我改进（RSI）只是针对失败症状反复打补丁式修改表面参数，容易陷入试错震荡、无法触及失败的底层机制。方法：SO-RSI 被动监控执行轨迹，检测 recurrence/opposing edits/expectation mismatch 三类结构异常后触发针对性机制调查，通过轻量诊断探针与跨轮持久化的 inquiry memory 累积因果证据，指导工作流的结构性编辑而非参数补丁。结果：在 Lean 4 证明生成与 Verus 可验证代码生成上，相同 24 小时搜索预算下最终 held-out 通过率比 Naive RSI 分别提升 21.8 与 25.8 个百分点，并显著抑制失败复发与零进展优化循环。

> 🔗 **与课题**：主要支撑环节①（工作流推理/流程规划）：论文把 agent 的工作流优化形式化为可诊断、可编辑的结构对象，并用执行反馈驱动工作流级（而非参数级）干预，可作为 GIS Task→Workflow 阶段自我修正机制的方法论参照。次要支撑环节⑦（评测）与⑥（训练/后训练）：其 recurrence、opposing edits、expectation mismatch 三类结构异常可作为工作流推理质量的自动诊断信号，用于构建迁移保持率、执行成功率之外的失败模式指标；persistent inquiry memory 的跨轮累积机制也可作为执行反馈驱动的持续改进/后训练信号来源。与②（结构化表示）有弱关联，因其编辑对象是 workflow 结构而非 DAG/依赖图本身；不涉及 tool/operator grounding 与跨平台迁移。

💡 **启发**：可把三类结构异常检测（复发/对冲编辑/期望失配）移植为 GEE→QGIS 迁移训练与推理中的工作流自诊断触发器：当模型反复生成同类错误算子或前后矛盾的 links 时，触发机制级排查而非继续重采样；同时用持久化 inquiry memory 记录跨轮诊断结论，避免零进展的重复生成循环。

⚠️ **局限**：实验仅限 Lean 4 与 Verus 两个形式化验证域，其“机制级诊断探针”依赖可快速执行的验证器与明确 pass/fail 信号，迁移到 QGIS 这类执行慢、失败原因模糊的 GIS 工作流时有效性未经检验。

### ⭐⭐⭐ EMG-FM-Bench: A Comprehensive Benchmark for Foundation Model Transfer and Adaptation on Electromyography
**6/10** · Tianhao Wu、Xu Wu、Amirmohammad Radmehr、Jiawei Yu、Yi Wu、Phuc Nguyen · arXiv · 2026-10-05 · [原文](https://arxiv.org/abs/2610.06450v1) · [PDF](https://arxiv.org/pdf/2610.06450v1)
*入选：能力迁移*

> 📄 **摘要**：Foundation models (FMs) are increasingly being developed for general time series and physiological signals, yet their transferability to downstream physiological tasks remains poorly understood. This question is particularly challenging for electromyography (EMG), where signal distributions vary substantially across users, sensing configurations, acquisition hardware, and downstream tasks. We introduce EMG-FM-Bench, a systematic benchmark for studying foundation-model transfer and adaptation on EMG. EMG-FM-Bench unifies 20 public datasets with over 1 million EMG segments and evaluates nine pretrained foundation models across four questions: how pretrained models perform when frozen or fully fine-tuned, how much pretraining helps compared with training the same model from scratch, how well models generalize to new users with limited labeled data, and how performance changes across different EMG tasks. Across the benchmark, linear probing provides useful information about pretrained representations, but full fine-tuning can substantially change downstream EMG performance. Comparing each pretrained model with the same model trained from scratch shows that the benefit of pretraining varies substantially across models and is not universal. Performance decreases when models are evaluated on new users, while five-shot adaptation improves macro-F1 in 70.2% of evaluated model-dataset combinations but recovers only part of the lost performance. Model performance is highly consistent between upper- and lower-limb classification and remains strongly correlated with continuous EMG-to-text decoding. Together, these results provide a systematic view of when pretrained time-series models transfer effectively to EMG and how their performance depends on fine-tuning, user variation, and downstream task.

**一句话**：提出 EMG-FM-Bench，统一 20 个公开 EMG 数据集、超 100 万片段，系统评测九个预训练基础模型在冻结/全微调、预训练增益、新用户泛化与跨任务表现四个维度上的迁移与适配能力。

痛点：基础模型在通用时间序列与生理信号上快速涌现，但其向下游生理任务的可迁移性缺乏系统理解，EMG 因用户、传感配置、采集硬件与任务差异大而尤为困难。方法：构建统一基准（20 数据集、100 万+ EMG 片段、9 个预训练模型），围绕冻结 vs 全微调、预训练 vs 同架构从零训练、少标签新用户泛化、跨任务变化四问做实证评测。结果：线性探针能反映预训练表征信息，但全微调会显著改变下游性能；预训练增益因模型而异并不普遍；新用户上性能下降，5-shot 适配在 70.2% 模型-数据集组合上提升 macro-F1，但仅恢复部分损失。

> 🔗 **与课题**：支撑环节③（能力迁移/跨域适配）与⑦（评测协议/基准设计）。对应关系：(1) 它给出源域→目标域的迁移实证范式，用"预训练 vs 同架构从零训练"隔离出迁移净增益，可直接类比我们要量化的 GEE 工作流知识→QGIS 的迁移保持率（transfer retention）；(2) 冻结/线性探针/全微调/少样本适配的多档协议，可映射到我们 DAPT/SFT/PEFT 等迁移手段的对照实验矩阵；(3) 跨用户、跨传感配置、跨任务的分布偏移评测，与跨平台（GEE→QGIS）分布偏移在方法论上同构，可借鉴其"恢复比例"式指标；(4) 但其迁移对象是生理信号表征而非工作流推理或工具落地能力，与①GIS Task→Workflow、④Operator grounding、⑤结构化图生成无直接关系，也不涉及 LLM/agent 语境，因此不属于核心 8-10 档。

💡 **启发**：借用其"预训练模型 vs 同架构从零训练"的对照设计，来分离并量化工作流推理能力的迁移净增益；其 few-shot（5-shot）适配与"部分恢复"度量方式，可改造为跨平台低资源落地时的迁移保持率与能力恢复比例指标。

⚠️ **局限**：研究对象是 EMG 生理信号的表征迁移，不涉及 LLM 工作流推理、tool grounding 或结构化生成，结论外推到"能力级迁移"需谨慎。

### ⭐⭐⭐ Cross-lingual Calibration of Pre-Generation Success Probes for Multilingual LLM Routing
**6/10** · Andrea Paganelli、Stefano Civelli、Pietro Bernardelle、Gianluca Demartini · arXiv · 2026-10-05 · [原文](https://arxiv.org/abs/2610.06216v1) · [PDF](https://arxiv.org/pdf/2610.06216v1)
*入选：能力迁移*

> 📄 **摘要**：Pre-generation success probes estimate response correctness from a language model's hidden activations before decoding, enabling cost-aware routing. While prior work has demonstrated their utility primarily on English inputs, we study their reliability across languages along three dimensions: (1) whether they preserve the ranking of likely successes and failures (DISCRIMINATION); (2) whether they retain probabilities that match observed success frequencies (CALIBRATION); and (3) whether they produce scores comparable enough across candidate models for cost-aware multilingual routing (UTILITY). Using 3,000 MATH problems in 10 languages and 8 open-weight model configurations, we compare cross-lingual transfer from English-trained probes and equal-budget pooled multilingual probes. English-trained probes retain useful cross-lingual discrimination but become less well calibrated after transfer. Pooled multilingual supervision improves both properties and yields more reliable estimates of success. In routing experiments, the pooled router achieves a 0.7% higher test success rate while reducing modeled cost by 13.0% relative to always selecting the model with the highest average success. These results show that multilingual routing requires success estimates that remain well calibrated and comparable across languages and models.

**一句话**：研究多语言 LLM 路由中"生成前成功探针"的跨语言判别力、校准与跨模型可比性，并用多语言池化监督改进探针。

痛点：用隐藏激活在解码前预测回答正确性（生成前成功探针）以实现成本感知路由的做法此前主要在英文上验证，跨语言是否可靠未知。方法：在 10 种语言、3000 道 MATH 题、8 个开放权重模型配置上，从判别力（能否保持成功/失败排序）、校准（概率是否匹配真实成功频率）、效用（跨候选模型是否可比）三个维度，对比英文训练探针的跨语言迁移与等预算的多语言池化探针。结果：英文探针跨语言仍保留有用判别力但迁移后校准变差，多语言池化监督同时改善判别与校准，路由实验在成功率提高 0.7% 的同时相对"总选平均成功率最高模型"降低 13.0% 建模成本。

> 🔗 **与课题**：主要支撑 ③（源域→目标域的能力迁移）与 ⑦（评测）。论文把"源语言上训练得到的能力（探针）迁移到目标语言"后的保持情况拆成两件可量化的事：排序/判别结构是否保持（transfer retention 的排序视角）、概率是否仍与真实成功频率对齐（校准漂移视角），这与课题中"GEE 上学到的 workflow reasoning 迁移到 QGIS 后保持率如何度量、是否退化"的评测设计同构，可直接借用其"迁移后保持 + 校准"双指标思路。但它迁移的对象是二分类正确性探针与路由决策，不涉及工作流推理、工具/算子 grounding 或 processes+links 结构化图生成，因此只属于支撑性方法论，而非核心问题研究。

💡 **启发**：可借其三维评测框架（判别保持 / 概率校准 / 跨候选可比）来设计 GEE→QGIS 迁移保持率与置信度校准指标；其"按预估成功率选择模型"的路由思想可类比为按预估可执行性为 QGIS operator grounding 选择候选路径。

⚠️ **局限**：任务局限于 MATH 题的正确性预测与模型路由，探针的跨语言结论能否外推到结构化工作流生成与工具/算子落地尚不可知。

### ⭐⭐ Discovered, Not Designed: Population Evolution for Collaborative and Compute-Intensive Model Discovery
**5/10** · Bo Peng、Lizhu Zhang、Yuhang Zhou、Mingyi Wang、Yifan Wu、Serena Li · arXiv · 2026-10-05 · [原文](https://arxiv.org/abs/2610.05950v1) · [PDF](https://arxiv.org/pdf/2610.05950v1)
*入选：能力迁移*

> 📄 **摘要**：LLM-driven evolution enables iterative model development, but two practical goals remain underexplored: finding model designs that transfer across related tasks and sustaining improvement when training is expensive. We introduce Population Evolution (PE), a collaborative, hierarchical framework that connects ongoing local searches through shared experimental evidence. PE evaluates code changes across related training instances and shares the results to guide subsequent proposals and promotion to larger training scales. For expensive targets, PE searches small training subsets and screens candidates through peer and intermediate evaluations before full-target training. We introduce RMD-Bench to evaluate both settings across ranking, watch-time prediction, RL algorithm discovery, and LLM/VLM pretraining. Compared with standalone evolution at matched source iterations, PE raises mean best local gains from 7.01% to 8.97% in ranking and from 2.84% to 3.85% in watch-time, while improving the best larger-scale outcome in all three joint-discovery families. In watch-time discovery, PE improves best larger-scale gains with four of five harnesses and all four proposers. On new recommendation datasets under shared target-side calibration, every evaluated PE design improves over the reference in mean performance. Under matched total GPU compute, completed LLM discovery runs yield a best relative accuracy gain of 2.48% and 13 successful candidates for PE, versus 0.92% and none for direct evolution. VLM loss reduction reaches 8.78% versus 5.05% under matched total GPU compute.

**一句话**：提出 Population Evolution(PE)——一个通过共享实验证据把多个局部 LLM 演化搜索连接起来的协作式分层框架，并发布 RMD-Bench 评测跨相关任务迁移与训练昂贵场景下的模型发现。

痛点：LLM 驱动的演化式模型开发在“发现能跨相关任务迁移的设计”和“训练昂贵时仍能持续改进”两个实际目标上研究不足。方法：PE 分层组织本地搜索，跨相关训练实例评估代码改动并共享结果以引导后续提议与向更大训练规模晋级；对昂贵目标先在小训练子集搜索，经同伴与中间评估筛选后再做全目标训练；用 RMD-Bench 在排序、观看时长预测、RL 算法发现、LLM/VLM 预训练上评测。结果：在匹配源迭代下 PE 把平均最优局部增益从 7.01% 提到 8.97%（排序）、2.84% 提到 3.85%（观看时长），匹配总 GPU 计算时 LLM 发现取得 2.48% 相对精度增益与 13 个成功候选（直接方法仅 0.92%、0 个）。

> 🔗 **与课题**：与课题的联系是间接的方法论层面，主要触及③与⑦，并弱关联②⑥。③能力迁移：论文明确以“跨相关任务的设计迁移”为目标，用共享实验证据、跨实例评估与晋级机制来提升迁移后的目标域表现，这种“源任务搜索→共享证据→目标任务筛选晋级”的协议与我们要研究的源域→目标域能力迁移在实验设计上可类比；但其迁移对象是模型设计/代码改动，不是 LLM 的工作流推理知识，因此不能算直接支撑。⑦评测：RMD-Bench 提出的“匹配源迭代数”与“匹配总计算量”两类对照口径，对设计迁移保持率、执行成功率这类指标的实验控制有直接借鉴价值。②结构化生成：搜索空间是代码级改动（code changes），属于结构化编辑/生成，但与 DAG、processes+links 图结构无关。⑥训练：小规模代理训练+同伴/中间评估+全量放大的分层筛选，实质是低成本训练与筛选策略，可作为储备框架。整体不涉及 GIS workflow reasoning、operator grounding 与 QGIS 图生成，属于跨领域的方法论外援而非核心竞品。

💡 **启发**：可借鉴“小数据子集搜索→同伴/中间评估→放大到全量”的课程式筛选与晋级机制，做 QGIS 结构生成的廉价预筛与验证协议；以及用共享实验证据池统一管理多模型/多工具在 workflow 迁移实验中的对照结果。

⚠️ **局限**：其“迁移”指模型设计跨任务迁移，与 LLM 工作流知识的跨平台/跨工具迁移并非同一概念，引用时须明确区分，避免把这套 AutoML/演化搜索结论直接外推到能力迁移。

### 🔥 ⭐⭐⭐⭐ SIGMAI: Secure GIS-AI Interface
**8/10** · L. S. C. MACIEL · Zenodo (CERN European Organization for Nuclear Research) · 2026-10-05 · [原文](https://doi.org/10.5281/zenodo.20389286)
*入选：领域×任务*

> 📄 **摘要**：SIGMAI is a QGIS plugin that lets AI assistants operate QGIS through a local, token-protected command interface instead of screen automation. It exposes a standards-compliant Model Context Protocol server, a consent layer that keeps the user in control of every action that changes the project or writes a file, and a cartographic engine that composes page-aware map layouts and audits them against an explicit, machine-readable rulebook.

**一句话**：SIGMAI 是一个 QGIS 插件，通过本地 token 保护的标准 MCP 服务器让 AI 助手直接操作 QGIS（而非屏幕自动化），并提供用户授权层与基于机器可读规则的地图版面组版/审计引擎。

痛点：AI 助手操作 GIS 通常靠 GUI 屏幕自动化，脆弱、不可审计、用户无法逐动作控制。方法：把 QGIS 能力暴露为符合 Model Context Protocol 标准的本地命令接口，加入 token 保护与逐动作同意层，再叠加一个 page-aware 版面组版引擎，用显式机器可读规则手册对结果做审计。结果：给出了 AI↔QGIS 的安全、可审计、结构化交互接口（系统/插件实现，未见大规模实证评测）。

> 🔗 **与课题**：①/②：论文把 GIS 操作抽象为标准协议上的结构化命令而非像素级自动化，与「Workflow→结构化表示」的思路同源，可作为 QGIS 侧结构化命令空间的参考定义。④（核心）：这正是我们管线末端「Workflow→QGIS Operator 落地」所需的 grounding 底座——模型不碰 GUI，而是通过 MCP 工具签名把算子/process 落到真实 QGIS 上，可直接作为我们 QGIS grounding 层的实现或对照实现。⑤：命令接口 + 机器可读规则手册 + 组版引擎，本质上是用声明式规则生成并约束结构化 GIS 产物（processes/links 之外的版面层），对应「结构化图生成 + 约束」的工程范式。⑦：对每个改变项目/写文件动作的 consent 检查与 rulebook 审计，天然构成幻觉算子/非法算子的拦截器与执行成功率的判定信号，可直接复用为评测协议。③（弱相关）：它是 GEE→QGIS 迁移的目标域接收端，但不研究迁移本身，只提供落地接口。
