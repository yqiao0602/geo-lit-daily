### 🔥 ⭐⭐⭐⭐ HTN Planning as a Coordination Layer for Multi-Server MCP Tool Orchestration
**8/10** · Eliott Jacopin、Éric Jacopin、Koichi Takahashi · arXiv · 2026-09-27 · [原文](https://arxiv.org/abs/2609.33731v1) · [PDF](https://arxiv.org/pdf/2609.33731v1)
*入选：工作流×工具推理*

> 📄 **摘要**：The Model Context Protocol (MCP) isolates servers by design: only the host can orchestrate cross-server workflows. When the host is a large language model, the resulting orchestrations are non-deterministic, non-reproducible, and pay one inference round-trip per tool call. We present a coordination architecture in which a Hierarchical Task Network (HTN) planner generates a verifiable cross-server plan once, and a runtime middleware executes it deterministically across multiple MCP servers, binding cross-action data dependencies via a template mechanism (\verb|${context.X}|) substituted at execution time. The architecture mirrors MCP's isolation constraint: each compound task decomposes into server-local primitive actions, and inter-server data flow is bound at execution time via JSON-path output extractors. We instantiate the architecture on five HTN domains spanning laboratory robotics, bioinformatics and multiscale modelling, and demonstrate end-to-end execution from a browser-based plan controller against eight live third-party MCP servers querying real biological databases.

**一句话**：提出用 HTN 规划器作为多服务器 MCP 工具编排的协调层，一次性生成可验证的跨服务器计划，再由运行时中间件确定性地执行并绑定跨动作数据依赖。

痛点：MCP 设计上隔离各服务器，跨服务器工作流只能由 LLM 主机编排，导致非确定性、不可复现，且每次工具调用都要付一轮推理往返。方法：用 HTN 规划器一次性生成可验证的跨服务器计划，运行时中间件通过模板 ${context.X} 与 JSON-path 输出提取器在执行期绑定跨动作数据依赖。结果：在实验室机器人、生物信息学、多尺度建模五个 HTN 域上实例化，并用浏览器端计划控制器对八个真实第三方 MCP 服务器完成端到端执行。

> 🔗 **与课题**：逐环节对照：①HTN 将 compound task 分解为 server-local primitive actions，正是任务分解与流程规划的形式化实现，为"GIS Task→Workflow"提供非 LLM 的规划器对照基线。④每个复合任务落地为具体服务器的原语动作，等价于把抽象工作流接地到可执行算子（operator grounding），与 Workflow→QGIS Operator 落地同构。⑤通过 ${context.X} 模板加 JSON-path 输出提取器在执行期绑定跨动作数据依赖，正是 processes+links 图中依赖闭合与数据流连边的机制化实现。⑦一次性生成、可验证、可复现的计划天然给出"结构正确/依赖闭合/可执行"的评测协议，对应执行成功率与幻觉算子率的度量。③跨服务器隔离约束下的编排可类比跨平台迁移（GEE→QGIS）：它主张把可迁移知识放在符号计划层而非模型内部，是本课题的重要竞争解释框架。整体上与"结构化 QGIS 图生成"高度同构，但它是符号规划而非模型学习，宜作为对比基线而非直接采用。

💡 **启发**：可直接借用 ${context.X} 模板 + JSON-path 输出提取器式的"执行期依赖绑定"机制，让模型只生成带占位符的骨架、把依赖解析推迟到执行期，降低结构生成耦合难度；并可借"先生成可验证计划、再确定性回放"的思路为 QGIS 图生成做确定性校验器。

⚠️ **局限**：依赖人工/符号化的 HTN 领域建模，未验证 LLM 能否习得跨服务器/跨平台的可迁移编排知识，且实验域为生物信息与机器人，无 GIS 语境。

🚨 **为什么必须重视**：它是"用确定性规划器替代 LLM 编排"的直接竞品路线，与本课题"模型内部可迁移工作流知识"的核心假设正面对撞，必须尽早界定分工并设为对照。其执行期依赖绑定与计划可验证性机制可直接迁移到 QGIS processes+links 的依赖闭合与执行成功率评测上。

### ⭐⭐⭐⭐ CodeSkill: Latent Skill Abstraction for Long-Horizon Code Agents
**7/10** · Song-Li Wu、Jingyi Wang、Zhaocheng Du、Weinan Gan、Weiwen Liu · arXiv · 2026-09-27 · [原文](https://arxiv.org/abs/2609.33243v1) · [PDF](https://arxiv.org/pdf/2609.33243v1)
*入选：能力迁移*

> 📄 **摘要**：Code agents require long-horizon decision-making over complex interaction trajectories. However, existing reinforcement learning (RL) approaches typically optimize behavior at the token level, creating a mismatch between low-level generation and high-level behavioral reasoning. This limitation leads to inefficient exploration and weak credit assignment under sparse rewards. Moreover, while large-scale agent trajectories often contain recurring multi-step behavioral patterns, their noisy token-level representations hinder effective experience reuse. To address these challenges, we propose CodeSkill, a framework that adapts hierarchical latent skill modeling to the code agent domain. CodeSkill first leverages a teacher model to distill both successful and failed trajectories into multi-level textual abstractions. It then integrates temporal variational inference with reinforcement learning to map these discrete semantics into continuous latent variables, while an adaptive boundary mechanism dynamically gates skill transitions based on execution feedback. The learned skills are injected into a frozen LLM policy as latent semantic prefixes, enabling optimization in a compact semantic space rather than over raw token sequences. By shifting RL from token-level exploration to experience-level reasoning, CodeSkill improves optimization efficiency and long-horizon behavioral coherence. Extensive experiments demonstrate that CodeSkill achieves highly competitive performance against strong open-weight baselines across diverse general and industrial coding benchmarks. Furthermore, the learned skills exhibit strong transferability and robust cross-domain generalization, highlighting the effectiveness of explicit behavioral abstraction for scalable agentic code generation.

**一句话**：提出 CodeSkill：用教师模型把代码智能体的成功/失败轨迹蒸馏成多级文本技能抽象，再用时序变分推断+RL 学成连续隐技能，作为潜语义前缀注入冻结 LLM 策略，实现经验级（而非 token 级）的长程决策优化。

痛点：现有代码智能体 RL 在 token 级优化，与高层行为推理错配，稀疏奖励下探索低效、信用分配弱，且轨迹中的多步重复模式被噪声化的 token 表示淹没，经验难以复用。方法：层级化隐技能建模——教师蒸馏多级文本抽象、时序变分推断把离散语义映射为连续隐变量、自适应边界按执行反馈门控技能切换，并将技能作为潜前缀注入冻结 LLM 策略。结果：在紧凑语义空间而非原始 token 序列上优化，长程行为一致性与优化效率显著提升，性能具竞争力。

> 🔗 **与课题**：支撑环节①（工作流推理/任务分解）与⑥（训练/后训练），并弱支撑②（结构化表示）。①：论文把长程交互轨迹抽象为分层技能，本质就是『任务→子步骤→技能边界』的工作流级分解与规划，与本课题『GIS Task→Workflow』同构，只是领域换成代码智能体。②：multi-level textual abstractions 是一种中间语义表示，但它被压成潜变量前缀而非显式 L3 语义层，为本课题『不依赖显式 L3 中间层是否可行』提供了对照性证据与反例视角。⑥：教师蒸馏（成功+失败轨迹）+ RL + 冻结策略上的潜前缀注入，属于蒸馏/PEFT/RL 结合的训练范式，正好落在我们的实现手段池内。⑦：长程一致性、稀疏奖励下信用分配、经验复用效率等评测口径可借鉴到迁移保持率与执行成功率的度量设计上。③：论文未做跨域/跨平台迁移实验，GEE→QGIS 的迁移保持率无法直接从中获得结论，需自行补足。

💡 **启发**：把『成功与失败轨迹都蒸馏为多级技能抽象、再以潜前缀注入冻结策略』直接搬成本课题的隐式中间层基线：GEE 工作流轨迹→隐技能层→QGIS 图生成，用来检验不显式建 L3 语义层时 QGIS processes+links 的依赖闭合率是否仍能保持。

⚠️ **局限**：领域局限于代码智能体的 RL 训练，未验证跨平台/跨工具迁移，且隐技能不可解释、难以外部校验（幻觉算子率一类指标无法直接度量）。

### ⭐⭐⭐⭐ EHRAdapt: Adapting Pretrained Language Models to Electronic Health Records with Semantic Priors for Rare Clinical Events
**7/10** · Andre R Goncalves、Vincent Liu、Priyadip Ray · arXiv · 2026-09-27 · [原文](https://arxiv.org/abs/2609.34007v1) · [PDF](https://arxiv.org/pdf/2609.34007v1)
*入选：能力迁移*

> 📄 **摘要**：Electronic health records (EHRs) encode clinical histories as (time, modality, code) tuples, whereas pretrained language models expect text tokens. Serializing them as text inflates sequence length and redundantly encodes structure. We introduce EHRAdapt, an adapter that maps tuples directly into a frozen language model's embedding space. Modality receives a learned embedding, time gaps enter through learned attention biases, and event codes receive dedicated vectors. Learning event vectors is the central challenge: clinical vocabularies are long-tailed, leaving rare events too few observations for reliable estimates. EHRAdapt therefore represents each event vector as the sum of a semantic prior and an evidence residual. The prior is a frozen embedding of the event's clinical description from a biomedical language model trained on clinical ontologies, mapped into the model's input space by a shared learned projection, so it supplies clinical meaning even when observations are scarce. The residual, a learned low-rank event-specific correction, refines it as evidence accumulates. We run continued pretraining on about 4 million patients' records with three frozen LLM backbones (OLMo2 1B, Llama3.2 1B, and OLMo2 7B), training only the adapter (0.1--0.6% of all parameters). The full adapter outperforms all ablations in held-out next-event prediction on every backbone. Removing the semantic pathway hurts rare events over ten times more than the most frequent ones, whereas removing the residual hurts overall prediction but improves it for the rarest events. On reportable infectious-disease and syndromic downstream classification tasks, EHRAdapt outperforms text-based LLM and count-based baselines, and both pathways improve rare-disease discrimination. The two pathways therefore play complementary roles, visible only when results are broken down by event frequency rather than averaged.

**一句话**：提出 EHRAdapt 适配器，把 EHR 的 (时间, 模态, 编码) 元组直接映射进冻结语言模型的嵌入空间，事件向量用语义先验加低秩残差表示。

痛点：EHR 本质是结构化元组而预训练语言模型只吃文本 token，序列化成文本会膨胀序列长度且冗余编码结构；同时临床词表长尾，罕见事件样本太少难以学到可靠的事件向量。方法：用一个轻量 adapter 把元组直接投影到冻结 LLM 的输入空间——模态用可学习嵌入、时间间隔用注意力偏置、事件码用专属向量，事件向量=生物医学模型给出的冻结语义先验（共享投影映射）+ 低秩证据残差，仅训练 0.1–0.6% 参数。结果：在 OLMo2 1B、Llama3.2 1B、OLMo2 7B 三个冻结骨干上持续预训练，全 adapter 在下一次事件预测上均优于所有消融；去掉语义通路对罕见事件的损害是高频事件的十倍以上。

> 🔗 **与课题**：主要支撑环节③（能力迁移中的源域→目标域适配）：论文研究如何把文本域预训练的基础模型迁移到结构完全不同的 EHR 元组域，且冻结骨干、只训适配器，正是“源域知识保护 + 目标域落地”的参数高效迁移范式。其次支撑环节⑥（后训练）：持续预训练 + adapter/PEFT 的训练配方与消融方法可直接借鉴。对环节⑦也有间接价值：其“按事件频率分层看性能退化”的消融式评测协议，可迁移为按算子频率分层的框架落地可用率/幻觉算子率分析。但它不涉及工作流推理、任务分解、依赖/DAG 结构化生成或 tool/operator grounding 本身，迁移的对象是输入表示与领域分布，而非模型习得的推理能力，因此属于方法层支撑而非核心问题撞车。

💡 **启发**：把长尾/稀有条目建模为“冻结语义先验 + 低秩证据残差”：可用预训练语义嵌入为罕见 QGIS 算子提供 grounding 锚点，再用少量数据学一个小残差纠正，直接对应幻觉算子率与长尾算子落地失败问题；另外“冻结骨干只训 adapter”的设定可作为跨平台迁移时保护源域工作流推理能力（transfer retention）的现成训练配方。

⚠️ **局限**：论文面向临床事件预测，本质是表示层/领域适配而非“能力迁移”，其迁移结论只在适配器层面成立，引用时不可过度类比为 GEE→QGIS 的推理能力可迁移性证据。

### ⭐⭐⭐⭐ Vestrum: Improving Agent Harnesses by Adapting Their Verification, Structure and Memory
**7/10** · Jayant Parashar、Eugene F. Douglass、William C. Bastian、Suchendra M. Bhandarkar · arXiv · 2026-09-27 · [原文](https://arxiv.org/abs/2609.33822v1) · [PDF](https://arxiv.org/pdf/2609.33822v1)
*入选：能力迁移*

> 📄 **摘要**：An agent harness controls how a language model accesses information, uses tools, preserves memory, and checks its work. Improving this software is costly when each evaluation requires a long interaction with an environment. We introduce Vestrum, a framework that turns failures in execution traces into scoped harness changes without training the task model. Its organizing overhypothesis is that tasks of a shared kind may exhibit recurring failures whose remedies transfer within that kind. Vestrum expresses failures as recognizable classes, proposes changes across verification, retrieval, decomposition, and knowledge synthesis, and screens their scope before evaluating them as a bundle. A persistent lessons file informs subsequent proposals. Across five settings and two baseline harnesses, the frozen harnesses improve held-out performance: UltraHorizon rises from 47.6 to 59.8 over GAM, Terminal-Bench 4 Hard from 63.7% to 70.3% of checks passed over Claude Code on eight held-out tasks at 1.03x test cost, and cell-type annotation agreement from 67.5% to 77.8% on held-out sections of one slide, alongside gains on LoCoMo and AMA-Bench. Across our searches, verification grounded in evidence helped both intermediate steps and final answers, at lower cost at intermediate steps, while critics asked to rebuild finished answers broke more than they repaired. On the three memory benchmarks, Vestrum also scores above the evaluated GEPA configurations in every paired evaluation.

**一句话**：Vestrum把agent执行轨迹中的失败归纳为可识别类别，在验证、检索、分解、知识合成四处提出harness层面的修改并复用，全程不训练任务模型。

痛点：改进agent harness依赖长交互评测，代价高昂。方法：以'同类任务存在可复现失败、其补救措施可在同类内迁移'为核心假设，将失败表达为类别，跨verification/retrieval/decomposition/knowledge synthesis提出修改，先筛查适用范围再成批评测，并用持久化的lessons文件指导后续提案。结果：UltraHorizon 47.6→59.8（GAM）、Terminal-Bench 4 Hard 63.7%→70.3%（Claude Code，1.03x测试成本）、细胞类型注释一致率67.5%→77.8%，并在三个记忆基准上超过GEPA配置。

> 🔗 **与课题**：主要支撑①③⑦。①：Vestrum显式对decomposition提出修改并筛查scope，本质是对任务分解/流程规划失败的自动修复机制，可为workflow reasoning提供可复用的错误-补救范式；③：其核心假设'同类任务的可复现失败及其补救可在同类内迁移'正是'源域→目标域'级的迁移实证，且以冻结任务模型为前提，提供了一种非训练式的迁移路径，可对照我们GEE→QGIS的能力迁移是否也能在冻结权重下靠外部lessons迁移；⑦：在5个setting、2个harness上做held-out评测并报告1.03x成本下的收益与'重建答案的critic反而破坏多于修复'的错误分析，可作为迁移保持率与落地可用率的评测协议参考。与②④⑤无直接关系（不涉及算子grounding或processes+links图生成）。

💡 **启发**：可借用两点：一是把失败模式固化为'可识别类+适用范围筛查'，迁移到跨平台场景即构造GEE→QGIS的workflow修复库/lessons文件，并用held-out任务度量迁移保持率；二是'verification grounded in evidence'在有证据的中间步骤上更省成本且更有效，可用于抑制QGIS幻觉算子率。

⚠️ **局限**：迁移发生在harness策略层而非模型内部知识，类目依赖人工设计且需failure trace，向完全异构工具链（GEE→QGIS）的泛化未经验证。

### 🔥 ⭐⭐⭐⭐ CompoWorld: Compositional Environment Scaling for General Agents
**8/10** · Xiao-Wen Yang、Weiyi Xu、Wen Da、Hang Xu、Canwei Li、Hong-Jie You · arXiv · 2026-09-27 · [原文](https://arxiv.org/abs/2609.33665v1) · [PDF](https://arxiv.org/pdf/2609.33665v1)
*入选：RL×LLM方法*

> 📄 **摘要**：Automatically generated environments provide a scalable source of interaction data for training general agents. However, existing approaches mainly generate tasks within a single environment, while real-world workflows require agents to connect information and actions across multiple services. We introduce Compositional Environment Scaling (\textbf{CompoWorld}), which expands the task space by composing a finite library of reusable services. Coding agents turn tool specifications into verified services with typed states and shared interfaces, while a world model handles tools that cannot be reliably implemented. A random-walk procedure connects services through dependency graphs, enabling the generation and verification of tasks that require information to flow across services. Verified trajectories support supervised fine-tuning (SFT), while our Completion-Focused Rubric Reward guides reinforcement learning (RL) toward full task completion by emphasizing criteria with lower pass rates within each rollout group. We construct 448 services exposing 10,130 tools and use 3K SFT trajectories and 1K RL tasks to train Qwen3.6-35B-A3B. Experimental results show that CompoWorld improves on its backbone by 9.17 points on average across eight benchmarks. On AutomationBench, it surpasses frontier models such as Claude Opus 4.6 and leads all compared agent-specialized 35B-A3B models.

**一句话**：CompoWorld 通过组合可复用服务库、用随机游走构建跨服务依赖图来生成并验证多服务任务，并以 SFT + 完成度奖励 RL 训练通用智能体。

> 🔗 **与课题**：主要支撑环节⑥训练/后训练中的蒸馏手段：论文重新审视 OPD 的损失设计，给出比 KL 更轻量、更聚焦关键 token 的蒸馏目标，属于可订阅的蒸馏解释框架（按校准标准 5-7 档）。次要触及环节③能力迁移：多教师蒸馏中的「跨域能力冲突」与样本级教师路由问题，与学生模型从 GEE 域吸收 workflow 推理能力、再迁移到 QGIS 域时可能遇到的源域/目标域能力冲突具有结构相似性，但其研究并非跨平台/跨工具迁移本身，也未涉及 GIS。与①②④⑤⑦无直接对应。
