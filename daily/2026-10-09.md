### 🔥 ⭐⭐⭐⭐ Cost-Aware and Self-Validating Multi-Agent Engineering of Computer-Vision Pipelines: An Optimization-Based Framework with Applications to Remote-Sensing Image Analysis
**8/10** · 新井 康平 · Information · 2026-10-07 · [原文](https://doi.org/10.3390/info17100986)
*入选：领域×任务*

> 📄 **摘要**：Remote-sensing image analysis increasingly requires workflows that combine heterogeneous sensors, geospatial preprocessing, deep-learning models, uncertainty estimation, and domain-specific quality control. Conventional computer-vision pipelines are commonly designed manually, making them expensive to develop, difficult to reproduce, and inflexible when sensor quality or task requirements change. Recent agentic-AI systems have demonstrated the feasibility of automatically planning and executing computer-vision and AutoML workflows, but computational cost, geospatial validity, recovery behavior, and provenance remain insufficiently integrated. This paper proposes COSA-CV, a Cost-aware and Self-validating Agentic Computer-Vision framework for automated engineering of remote-sensing image-analysis pipelines. COSA-CV consists of specialized agents for task interpretation, dataset auditing, remote-sensing context analysis, pipeline planning, model and tool routing, image preprocessing, inference, post-processing, validation, error diagnosis, recovery, uncertainty estimation, cost monitoring, and report generation. Pipeline selection is formulated as a constrained multi-objective optimization problem that jointly considers predictive quality, processing latency, GPU usage, memory consumption, energy, tool-call cost, reliability, and human-review burden. The workflow is implemented as a stateful graph with conditional edges that dynamically select optical, SAR, or multimodal processing routes according to image quality, validation results, uncertainty, and computational budget. The evaluation includes two case studies: Sentinel-2 land-cover classification using EuroSAT and multimodal flood-region extraction using SEN12-FLOOD. The numerical results reported here are an illustrative worked example rather than measurements from real experiments, used only to demonstrate the framework’s evaluation protocol and reporting format. In this hypothetical setting, COSA-CV is illustrated as reaching 94.7% accuracy and a 94.3% macro-F1 score for land-cover classification, and 85.2% Dice, 74.3% IoU, and 70.1% boundary F-score for flood-region extraction, with reduced computational cost and invalid-output acceptance relative to non-optimized multi-agent baselines. A final implementation must replace these illustrative values with results from real experiments before any of these comparative claims can be considered validated.

**一句话**：提出 COSA-CV——一个成本感知、自验证的多智能体框架，用约束多目标优化和带条件边的状态图自动规划、执行与校验遥感计算机视觉流水线。

痛点：遥感CV流水线通常人工设计，开发昂贵、难以复现，且难以适应传感器质量或任务需求变化；已有 agentic-AI 系统虽能自动规划执行 CV/AutoML 流程，但计算成本、地理空间有效性、错误恢复与溯源未被统一整合。方法：COSA-CV 由任务解释、数据集审计、遥感语境分析、流水线规划、模型与工具路由、预处理、推理、后处理、验证、错误诊断、恢复、不确定性估计、成本监控、报告生成等专用智能体组成，把流水线选择建模为联合考虑预测质量、延迟、GPU/内存、能耗、工具调用成本、可靠性、人工复核负担的约束多目标优化问题，并将工作流实现为带条件边的有状态图以动态选择光学/SAR/多模态处理分支。

> 🔗 **与课题**：逐环节对照：①直接对应——其“pipeline planning agent”就是把 GIS/遥感任务分解为可执行处理步骤的工作流推理，与本课题 Route-2 的“GIS Task→Workflow”同轴；②直接对应——“workflow implemented as a stateful graph with conditional edges”正是依赖组织+结构化流程图的显式生成，可作为 QGIS processes+links 图结构设计的同构参照；④部分对应——“model and tool routing”在地理空间语境下做算子/工具选择与落地，与 QGIS operator grounding 的目标（选对算子、接对参数）机制类似，但它是路由选择而非 LLM 内部 grounding 能力；⑦部分对应——自验证、错误诊断、恢复与成本监控构成一套执行期校验与错误分析协议，可迁移为 QGIS 图生成后的依赖闭合/可执行性检查与幻觉算子率度量；③不涉及——全文没有跨域/跨平台（GEE→QGIS、tool→tool）能力迁移的实证，也没有针对模型内部工作流知识可迁移性的训练/评测设计，故不支撑本课题的核心迁移问题。

💡 **启发**：可直接借用两点：一是把“流程候选选择”写成带约束的多目标优化（质量/延迟/成本/可靠性/人工负担），可作为 QGIS 工作流生成后的重排序与代价约束解码打分器；二是把生成的工作流表示成带条件边的有状态图，并挂接 self-validation + error-diagnosis + recovery 循环，用执行反馈回灌修正图结构。

### 🔥 ⭐⭐⭐⭐ AgentEvolver: System-Wide Self-Evolution Through Task Execution
**8/10** · Wentao Zhang、Fuchao Yang、Yilei Zhao、Xinrun Wang、Bo An · arXiv · 2026-10-08 · [原文](https://arxiv.org/abs/2610.11613v1) · [PDF](https://arxiv.org/pdf/2610.11613v1)
*入选：能力迁移*

> 📄 **摘要**：An agent can complete a task without improving how it works. Turning task experience into reusable capability requires connecting the changed component to its evaluation and subsequent use. We present AgentEvolver, a system for developing capabilities during task execution while keeping the foundation model fixed. Eight entity families expose reusable operations, methods, agents, control flow, interfaces, and supporting state to revision through a common versioned lifecycle. A shared Runtime coordinates ongoing work, while persistent planning and recoverable context preserve task direction and supporting evidence. We evaluate task outcomes on SWE-bench Pro Public and examine capability changes in six application cases. The team reports an 82.08\% resolution rate with evolution, exceeding its reported baseline without evolution. The cases show retained capabilities entering later website, game, and research work, while also documenting incomplete objectives and an unsuccessful strategy. These findings distinguish improvement in a reusable component from success on the final task. AgentEvolver provides a concrete basis for studying capability accumulation through execution; independent-task transfer and total development cost remain open questions.

**一句话**：提出 AgentEvolver 系统，让 LLM 智能体在冻结基础模型权重的前提下，通过任务执行对八类可复用实体（操作、方法、智能体、控制流、接口等）做统一版本化修订，把任务经验沉淀为可复用能力。

痛点：智能体能完成任务却不会改进工作方式，任务经验难以转化为可复用能力，改变了的组件与它的评测、后续复用之间缺少连接。方法：以统一版本化生命周期暴露八类实体族，配合共享 Runtime、持久化规划与可恢复上下文，在基础模型固定的情况下边执行边演化。结果：SWE-bench Pro Public 上达 82.08% 解决率（高于无演化基线），并在网站、游戏、科研等后续案例中观察到能力留存，同时记录了未达目标和一次失败策略，作者指出独立任务迁移与总开发成本仍是开放问题。

> 🔗 **与课题**：逐环节对照：③能力迁移——论文核心正是把任务执行中获得的改变沉淀为可复用组件并带入后续网站/游戏/科研任务（retained capabilities entering later work），且明确把 independent-task transfer 列为开放问题，与研究关注点'迁移保持率 transfer retention'直接对应，属源域→目标域的能力迁移实证研究。①GIS Task→Workflow——其 persistent planning 与控制流实体的可修订性说明规划本身可被复用与改进，为工作流推理的可持续积累提供机制参照。⑤结构化 QGIS 图生成——八类实体族（operations/methods/control flow/interfaces/state）以统一版本化生命周期组织依赖与接口，可类比 processes+links 图的依赖闭合与版本管理。⑥训练/后训练——提出'冻结基础模型、靠系统级组件修订实现能力积累'的非参数化路径，是 DAPT/SFT/LoRA/蒸馏之外必须对比的替代框架。⑦评测——强调区分'可复用组件改进'与'最终任务成功'并记录失败策略，可支撑工作流质量、幻觉算子率与失败分析的指标设计。

💡 **启发**：可借其'八类实体族+统一版本化生命周期'的组件级演化账本，把 QGIS processes/links 图的每个算子与依赖当作可版本化、可评测、可复用的实体来追踪能力沉淀，而非只看最终图能否执行；并用'组件改进 vs 任务成功'双轨指标避免评测只盯生成成功率。

⚠️ **局限**：迁移证据来自少量应用案例而非受控跨域/跨平台实验，缺少迁移保持率的量化，且基础模型冻结使其结论难以直接外推到权重层面的能力迁移。

🚨 **为什么必须重视**：该论文直接以'任务执行中沉淀可复用能力并迁移到后续任务'为核心，与本课题的'能力迁移+迁移保持率'撞题，且把 independent-task transfer 明确列为开放问题，说明这正是当前前沿未解点。其组件级版本化演化机制可作为 GEE→QGIS 能力留存与评测协议的强竞争者或直接借鉴的基线框架，必须立即精读比对。

### 🔥 ⭐⭐⭐⭐ Tracing the Thoughts of a Coding Agent Playing ARC-AGI-3: Lessons for Continual Learning
**8/10** · Chen Wu、Josh Passenger、Yin Song · arXiv · 2026-10-08 · [原文](https://arxiv.org/abs/2610.11450v1) · [PDF](https://arxiv.org/pdf/2610.11450v1)
*入选：能力迁移*

> 📄 **摘要**：We study how a coding agent learns across a sequence of abstract reasoning tasks. The agent runs on a frozen foundation model inside a fixed harness and acts by writing and running Python and shell scripts. It retains no state across turns other than its written artifacts, so every thought it forms, carries, corrects or abandons leaves a trace, where a thought is any belief, rule or plan committed to a file. We let the agent play ARC-AGI-3, a set of interactive reasoning games that provide no instructions. Each game is a sequence of levels, and a strategy that clears one level can fail on the next, so every new level is in effect a new task. The agent records what it learns as Python scripts and text notes, while the harness keeps a complete log of every action and observation. Our contribution is a measurement protocol that traces each thought through these files, from the task where it forms to the task where it is corrected or abandoned, applied to seven evaluation runs with three backbones from two model families. Scripts written for one task are almost never called again in a later task (33 of 630 references cross a task boundary), because most scripts embed the state of the current level. Instead, the agent rewrites its knowledge into new scripts, keeping the general rules and dropping the level-specific details, and abandons 74% of the scripts it wrote before a boundary. The notes, which only the model reads, are never revised: the agent appends without removing earlier claims, and the contradictions that accumulate are settled against the log. Because the log preserves everything, the agent forgets selectively, not catastrophically. The most costly error is a hard-coded value carried into a task where it no longer holds. These findings come from the files the agent wrote, without access to the model, and constitute a white-box analysis of how a coding agent continually learns.

**一句话**：让一个基于冻结基础模型、只能靠写 Python/shell 脚本行动的编码智能体玩 ARC-AGI-3，并用一套测量协议追踪每条'想法'（脚本与笔记）在跨任务边界时的形成、修正与废弃。

痛点是智能体在多任务序列中'跨任务知识迁移'几乎不可观测：状态只以脚本/笔记形式外化，需要方法才能追踪。作者提出一套测量协议，把每个信念/规则/计划视为写入文件的'想法'，追踪它从形成任务到被修正或废弃任务的轨迹，并在 7 次评测运行、2 个模型家族 3 个骨干上验证。结果发现脚本几乎不跨任务被复用（630 次引用仅 33 次跨边界），原因是脚本内嵌了当前关卡状态；智能体更倾向把知识重写为新脚本，跨边界前废弃 74% 的脚本，而只给模型自己看的笔记从不修订、只追加。

> 🔗 **与课题**：主要支撑环节③（能力迁移/跨任务跨域迁移）与⑦（评测）：论文核心正是度量'前一个任务学到的可复用工作流知识能否迁到下一个任务'，其 transfer 度量（跨任务引用率 33/630、跨边界前废弃率 74%）与我方'迁移保持率 transfer retention'指标在概念与操作化上高度同构。同时部分支撑①：ARC-AGI-3 每个新关卡即新任务，智能体必须做任务分解与策略规划，脚本+笔记即其外化的 workflow 表示；以及⑤/②的弱关联：脚本可视为一种结构化、可执行的产物（但非 DAG/graph 形式）。方法学上'把想法物化为文件、用日志追踪其全生命周期'可直接移用为我方 GEE→QGIS 迁移实验中 workflow 知识的追踪协议。此外它印证了一个关键假设：模型倾向保留通用规则、丢弃平台/状态特化细节——这与'想在 GEE 上学的 workflow 推理迁移到 QGIS operator grounding'的可行性问题直接相关。

💡 **启发**：可直接借用其'想法=写入文件的制品 + 全量 action/observation 日志'的追踪协议，为我方 GEE→QGIS 迁移实验设计'workflow 知识制品级'的跨阶段追踪，得到类似'script 跨任务引用率/废弃率'的 transfer retention 指标；其'保留通用规则、剥离平台特化细节'的重写模式可作为迁移成功/失败的诊断信号。

⚠️ **局限**：任务域为 ARC-AGI-3 抽象推理游戏、制品是脚本+笔记而非结构化工作流图，且无 GIS/tool-grounding 场景，迁移到 QGIS operator 落地时需重新论证外部效度。

🚨 **为什么必须重视**：它与我方核心科学问题正面撞车：'冻结模型 + 固定 harness 下，跨任务的工作流/脚本知识能否迁移、以什么形式迁移'正是我们关心的 transfer 命题，且它给出了可复用的量化协议和反直觉结论（脚本几乎不跨边界复用、知识靠重写而非复用）。若不立即跟进，我方'transfer retention'指标的定义与基线很可能被这篇先行占位。

### 🔥 ⭐⭐⭐⭐ Harness Compilation: Which Decisions Should a Small Vision-Language Model Keep?
**8/10** · Minhao Fan、Yinyi Liu、Jiayu Zhao、Zihan Teng、Song Chen、Weichen Liu · arXiv · 2026-10-08 · [原文](https://arxiv.org/abs/2610.11231v1) · [PDF](https://arxiv.org/pdf/2610.11231v1)
*入选：能力迁移*

> 📄 **摘要**：Small vision-language models may be able to read external evidence yet struggle to obtain it. We introduce Harness Compilation (HC), an offline procedure that adapts the division of work between a frozen small VLM and its external harness. A large teacher uses student execution traces to revise reusable content and control, while a separate validation set selects the deployed harness. Deployment requires neither weight updates nor teacher calls. Across seven visual question-answering settings with students of at most 9B parameters, HC improves scores over bare students by 9.9-23.9 points, averaged over three independent builds per setting. Interventions on five runtime decision types (invocation, selection, argument generation, evidence integration and abstention) show why this allocation matters: requesting evidence and generating open queries can be costly, whereas bounded choices and reading supplied text can remain useful student work. Fact cards benefit all ten evaluated students, but decision policies transfer unevenly. Recompilation for a new student model helps when the transferred interface no longer fits the student. With 100 practice items, HC exceeds answer-only LoRA on three tasks. Larger training budgets can match or surpass a fixed harness, while combining the two improves SlideVQA beyond either alone. These findings support allocating work from measured student behavior rather than uniformly removing decisions.

**一句话**：提出 Harness Compilation：用大模型教师根据小 VLM 的执行轨迹离线改配「学生模型保留哪些决策、外部 harness 承担哪些决策」，部署时无需更新权重或调用教师。

痛点是小 VLM 能读外部证据却难以自主获取证据，模型与外部工具之间该由谁做哪些决策缺乏依据。方法是用教师分析学生执行轨迹，修订可复用的内容与控制（五类运行时决策：调用、选择、参数生成、证据整合、弃答），并用独立验证集挑选最终 harness，全程离线、部署零权重更新。结果在七个 VQA 设置下比裸学生模型提升 9.9–23.9 分，发现决策策略在学生间迁移并不均匀，换学生需重新编译，100 条练习样本即超过 answer-only LoRA，harness 与 LoRA 组合还能进一步提升。

> 🔗 **与课题**：主要支撑环节③能力迁移：论文的核心实证正是「决策策略能否从一个模型迁移到另一个模型」，发现 transfer 不均匀、接口不匹配时需针对新学生重新编译——这与课题关心的迁移保持率（transfer retention）与目标域重新适配完全同构。其次支撑环节②Workflow→结构化表示：作者把 agent 行为显式拆成 invocation / selection / argument generation / evidence integration / abstention 五类决策，形成可复现的结构化决策清单，相当于工作流语义的最小结构单元。也触及环节④grounding：调用、算子选择与参数生成正是 operator grounding 的决策切面，论文回答了「哪些 grounding 决策该留给模型、哪些该交给外部 harness」。环节⑥训练/后训练：给出无权重更新的 harness 编译作为 SFT/LoRA 的对照，并证明二者可叠加（SlideVQA 超过单独任一），为 QGIS 落地提供非微调路线。环节⑦评测：每设置三次独立构建取均值、对五类决策做干预实验、分决策类型报告迁移效果，是可借用的迁移保持率评测协议。

💡 **启发**：把「迁移保持率」按决策类型拆开测量（调用/选择/参数生成/整合/弃答分别算保持度），而不是只报一个总准确率；并把 harness 重编译当成平台切换（GEE→QGIS）时的轻量适配手段，与 LoRA 组合使用而非二选一。

⚠️ **局限**：实验全部落在 VQA 式证据检索场景，小模型≤9B，harness 是外部证据读取而非真实 GIS 算子 API，决策拆解中不含明确的依赖/DAG 组织，因此对 QGIS processes+links 结构生成的直接证据有限。
