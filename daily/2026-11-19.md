**8/10** · Zhengfeng Yu、Tian Lan、Zhijing Wu、Enbo Zhao、Xuannan Liu、Feihu Jiang · arXiv · 2026-11-17 · [原文](https://arxiv.org/abs/2611.22777v1) · [PDF](https://arxiv.org/pdf/2611.22777v1)
*入选：工作流×工具推理*

> 📄 **摘要**：Executable synthetic environments provide scalable training tasks and verifiable feedback for long-horizon agents. Existing environment synthesis methods primarily generate tasks within individual environments. However, these tasks do not adequately capture real-world interactions across services, where actions in one service depend on information obtained from another. Synthesizing such tasks is challenging because data generated across environments must remain consistent to support executable and verifiable interactions. To address this challenge, we introduce CrossEnv, a framework that uses an entity-tool graph to identify connections between environments and aligns task-specific data to synthesize executable, verifiable cross-environment tasks. We further propose CrossEnv-Curriculum, which progresses from single-environment tool use to coordination across more environments and business domains, before introducing user interaction. Across four external benchmarks, combining cross-environment training data with this curriculum achieves competitive performance with fewer training examples. Further analyses support the benefits of cross-environment data and curriculum training, and provide evidence of transfer to new environment combinations, external tasks less similar to the training data, and longer workflows.

现有可执行合成环境多为单环境任务，无法刻画真实世界中跨服务依赖（一个服务的动作依赖另一服务的信息），而跨环境合成又要求数据一致才能可执行、可验证。作者用实体-工具图识别环境间连接、对齐任务专属数据，合成跨环境任务，并提出从单环境工具使用到多环境、多业务域协同、最后引入用户交互的 CrossEnv-Curriculum。在四个外部基准上以更少训练样本取得有竞争力性能，并给出向新环境组合、低相似外部任务与更长工作流迁移的证据。

### 🔥 ⭐⭐⭐⭐ Option-GRPO: Hierarchical RL Against AI Slop in Code Generation for Unseen SDKs
**8/10** · Prashank Kadam · arXiv · 2026-11-17 · [原文](https://arxiv.org/abs/2611.23633v1) · [PDF](https://arxiv.org/pdf/2611.23633v1)
*入选：RL×LLM方法*

> 📄 **摘要**：Large language models increasingly produce AI slop in generated code: verbose, redundant, non-idiomatic implementations that pass functional checks but bloat codebases. The problem compounds on SDKs released after the model's training cutoff, where the model has neither idiomatic priors nor compositional understanding. We present Option-GRPO, a hierarchical reinforcement learning framework that adapts a code LLM to an unseen SDK from its source code alone, without human-written usage examples or test cases, and that explicitly optimizes for both functional correctness and code elegance. Our key insight is that SDK source code contains compositional structure that defines a hierarchy of reusable code patterns (code options) which simultaneously serve as the building blocks of a curriculum and the action space for efficient policy optimization. We show that code options induce a valid semi-Markov decision process, give conditional bounds under which shorter option description length implies more concise and, in expectation, more API-efficient programs, and analyze under stated assumptions how the option hierarchy improves credit assignment by a factor of $\sqrt{T/K}$. Using Group Relative Policy Optimization (GRPO) with execution-based rewards at each curriculum level, Option-GRPO discovers SDK idioms, composes them into patterns, and assembles patterns into complete programs. Experiments on 12 unseen SDKs with a 32B-parameter base model demonstrate 61.4% pass@1, outperforming flat GRPO by 8.7 points, ExploraCoder by 11.2 points, and ReCode by 6.3 points. Option-GRPO produces solutions that use 34.7% fewer API calls and are 27% shorter than flat-GRPO outputs while maintaining higher correctness, directly attacking the slop problem.

**一句话**：提出 Option-GRPO 分层强化学习框架，仅凭 SDK 源码构建可复用代码模式（option）的层次结构作为课程与动作空间，用 GRPO+执行奖励让代码 LLM 适配训练截止后发布的全新 SDK。

痛点：LLM 生成的代码在未见过的 SDK 上既啰嗦又不地道（AI slop），且缺少惯用先验与组合理解，而人工示例/测试不可得。方法：从 SDK 源码中抽取组合结构形成 option 层级，证明其构成半马尔可夫决策过程，并给出描述长度-API 效率的条件界与信用分配改进分析，用执行奖励的分层课程 GRPO 训练。结果：12 个未见 SDK、32B 基座模型上 pass@1 达 61.4%，优于对照。
