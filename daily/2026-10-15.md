### 🔥 ⭐⭐⭐⭐ FHIR-AgentEval: a modular sandbox for benchmarking clinical LLM agents with memory-augmented configurations
**8/10** · Youssef Mokssit、Kamalakkannan Ravi、Mengshu Nie、Junyoung Kim、Cong Liu · npj Digital Medicine · 2026-10-10 · [原文](https://doi.org/10.1038/s41746-026-03348-0)
*入选：工作流×工具推理*

> 📄 **摘要**：Healthcare data exchange increasingly relies on HL7 FHIR, but FHIR’s implementation complexity creates barriers for clinical workflows. Large language model (LLM) agents could bridge this gap by translating natural language requests into structured FHIR operations, yet their reliability remains unproven. We present FHIR-AgentEval, an extensible evaluation sandbox comprising 43 modular tasks for benchmarking LLM agents on realistic appointment management and genetic testing workflows. Each task executes against a resettable FHIR server with custom deterministic validation of both agent responses and resulting server state. We run an ablation study of five agent configurations, varying access to an on-demand FHIR R4 specifications server and long-term memory trained with or without specification grounding. Across four experimental settings, memory consistently improves task success and reduces strategic failures such as incorrect tool selection and resource-type confusion. On held-out tasks, the best memory configuration improves success by 9.1% over baseline, offering a potential pathway toward more robust clinical deployment.

**一句话**：提出 FHIR-AgentEval——一个可扩展的临床 LLM agent 评测沙箱（43 个模块化任务），在可重置的 FHIR 服务器上把自然语言请求映射为结构化 FHIR 操作，并系统消融长时记忆与规范（spec）接地配置。

痛点：HL7 FHIR 规范复杂，LLM agent 虽可把自然语言翻译成 FHIR 操作，但可靠性未被验证，且缺乏能同时校验 agent 回答与服务器最终状态的评测手段。方法：构建含 43 个任务（预约管理、基因检测工作流）的可重置 FHIR 沙箱，对响应与生成的服务器状态做确定性双重校验，并消融五种 agent 配置（是否可访问按需 FHIR R4 规范服务器、是否用规范接地训练的长时记忆）。结果：四种实验设置下记忆一致提升任务成功率、减少错误工具选择与资源类型混淆等策略性失败，最佳配置在留出任务上比基线提升 9.1%。

> 🔗 **与课题**：支撑环节③（能力迁移/NL→API）：论文核心正是把自然语言指令落地为结构化 API 操作（FHIR RESTful 操作），属于 NL→API、tool→tool 的跨表征接地实证，与 GEE→QGIS 的跨平台算子迁移同构。支撑环节④（operator grounding）：它显式研究 agent 能否正确选择工具与资源类型，并把"错误工具选择""资源类型混淆"作为可量化失败模式——这正是幻觉算子率/算子落地可用率的直接对应物。支撑环节⑦（评测）：可重置服务器 + 对 agent 响应与生成后服务器状态做确定性校验的双通道评测协议，可直接迁移为 QGIS 图生成的"结构正确性 + 执行成功率"双指标评测框架。支撑环节⑥（训练/后训练）：长时记忆"带/不带规范接地"训练的消融，等价于本课题关心的"知识注入方式是否影响下游 grounding 正确率"，可作为 DAPT/SFT 之外的一种轻量适配基线。此外 43 个模块化任务的分解粒度与 9.1% 的 transfer/held-out 增益报告方式，为本课题的迁移保持率（transfer retention）指标设计提供了可借鉴的留出集协议。

💡 **启发**：可直接偷两点：(1) "双通道确定性校验"——不仅评 agent 文字输出的正确性，还执行并校验落地后的系统状态，这正好可用于 QGIS processes+links 的依赖闭合与可执行性判定；(2) 把"规范服务器是否可访问"和"记忆是否经规范接地训练"作为两个正交消融轴，可搬到 QGIS 场景做同样的 2×2 消融，用来定位迁移失败究竟来自算子知识缺失还是接地检索缺失。

⚠️ **局限**：任务仅 43 个且限定预约管理与基因检测两个窄工作流，FHIR 的扁平资源操作结构远不如 GIS 工作流的 DAG 依赖复杂，结论向多步依赖组织场景外推需谨慎。

## 🤖 GIS Agent 与工具使用（1 篇）

### ⭐⭐⭐ Beyond Generation: What a Decision-Native Model Does Well in a Long Task, and What It Needs from Its Harness
**6/10** · Xuanming Cao · Zenodo (CERN European Organization for Nuclear Research) · 2026-10-13 · [原文](https://doi.org/10.5281/zenodo.23322724)
*入选：能力迁移*

> 📄 **摘要**：Many automated workflows end in a bounded decision among options that the software already knows, yet such decisions are usually obtained from language models by generating text. Decision-native models instead return one of the supplied options together with a probability distribution. We study one of them, Jev, on the Three-Phase Vault, a puzzle small enough to be solved exactly (65,375 states, a 26-move optimum), so that every step of every run can be scored against the optimum. On 400 fixed states with identical inputs, Jev chose an optimal action more often than three reasoning models (53.0% against 28.5–36.3%), at a median latency of 0.41 seconds against 2.3–4.4 seconds. Over whole runs, however, Jev often undid its own progress and completed 22% of runs under a minimal harness, against 86%, 32% and 26% for the reasoning models. A harness that kept a persistent goal and filtered the options by it raised Jev's completion from 0% to 94% (141 of 150 runs), and replaying the original code three and a half weeks later gave 48 of 50. Small changes then reduced completion sharply: shuffling the order of the options (18 of 50), rewording the goal instruction (32 of 50) and keeping drop actions in the filtered set (4 of 70). On twelve generated environments the filter's gain was not statistically reliable, and removing drop actions, which helped on the Vault, lowered completion there from 73% to 13%. The performance of a decision-native model on a long task thus depends on a harness whose effect is large and fragile, and building harnesses that transfer is the main open problem. Preprint, not peer reviewed. Data, code and all recorded runs: doi:10.5281/zenodo.23323117.

**一句话**：在一个可精确求解的小型谜题（Three-Phase Vault）上对比"决策原生模型"Jev与三个推理型LLM，并研究外部harness（持久目标+选项过滤）对长程任务完成率的影响。

痛点：现有自动化工作流常只需在软件已知的候选项中做有界决策，但通常靠LLM生成文本得到，长程执行中容易反复推翻自己的进展。方法：让决策原生模型直接返回候选项及其概率分布，在65,375状态、26步最优解的谜题上对400个固定状态逐步打分并与最优解对齐，同时消融harness（持久目标、选项过滤、选项顺序、指令措辞、是否保留drop动作）。结果：Jev单步选中最优动作率53.0%远高于推理模型的28.5–36.3%且延迟更低（0.41s vs 2.3–4.4s），但整轮完成率仅22%，加harness后从0%提升到94%；对harness的微小扰动即导致完成率大幅下降，且在12个生成环境上过滤增益统计上不可靠。

> 🔗 **与课题**：主要支撑⑦评测，部分触及①工作流推理。论文最核心的方法论贡献是把"单步最优决策率"与"整轮任务完成率"分开度量，并证明二者严重背离（单步最优53%但整轮仅22%，甚至0%完成）——这正好对应我们评测QGIS图生成时必须区分"单算子grounding准确率/幻觉算子率"与"整图依赖闭合+执行成功率"，二者的gap本身就是可报告的指标。其次，harness（持久目标+按目标过滤候选）相当于在解码/规划阶段施加约束以抑制无效动作，可与我们的④grounding与⑤结构化图生成中的约束解码思路对接，用于降低幻觉算子率。第三，它系统消融了选项顺序、指令措辞、候选集构成对完成率的影响，为我们的评测协议稳健性检查（提示词/候选顺序敏感性）提供了可借鉴的实验设计。但论文不涉及跨域/跨平台能力迁移（③）、不涉及工具/算子落地（④）、不涉及DAG/依赖结构生成（②⑤），也无训练后训练成分（⑥），因此只是方法论层面的外围支撑。

💡 **启发**：把"单步最优率"与"端到端完成率"作为两个独立指标并列报告，并做harness/提示扰动的稳健性消融（选项顺序、指令措辞、候选集构成），可直接搬到QGIS算子grounding评测中衡量幻觉算子与执行失败的差距。

⚠️ **局限**：仅在单一小型可穷举谜题上验证，样本量小（如50次replay、150次run），且作者自己承认在12个生成环境上过滤增益统计不可靠，外部效度与跨域泛化性存疑。
