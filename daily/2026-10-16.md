### 🔥 ⭐⭐⭐⭐ STRATA: Self-Maintaining Structured Experience Graphs for Self-Evolving Language Agents
**8/10** · Guanhua Zhu、Hanwen Li、Zhi Wei、Mengnan Du、Chenxi Yuan · arXiv (Cornell University) · 2026-10-14 · [原文](https://doi.org/10.48550/arxiv.2610.19386)
*入选：能力迁移*

> 📄 **摘要**：Large language model (LLM) agents can self-evolve at test time by accumulating experience: retrieving relevant memories before acting and writing new lessons back afterwards. Yet most are single-level: trajectories, distilled workflows and reasoning items all land in one undifferentiated pool indexed by embedding similarity, with no typed abstraction hierarchy. They never forget or deduplicate, and are prone to negative transfer, where a superficially similar but directionally opposite experience is recalled and its concrete steps are copied verbatim, actively harming the agent. We introduce STRATA, a structured, outcome-grounded, self-maintaining memory that organizes experience into a three-layer graph of atomic skills and code snippets, task workflows and generalized meta-frameworks, connected by typed edges. STRATA maintains itself through five mechanisms sharing one similarity geometry: a multi-dimensional similarity that scores retrieval by operation and target; a typed reflector crystallizing procedures from successes and pitfalls from failures; community detection that induces meta-frameworks; pressure-triggered garbage collection with articulation-point protection; and contrast edges that flag confusable, direction-opposite experiences. Across four interactive benchmarks (AppWorld, WebArena, ALFWorld, ScienceWorld), two frozen backbones and seven baselines, STRATA attains the best average score while simultaneously using the lowest latency and fewest environment steps of any memory-augmented method, and 44% fewer lines of injected memory than the most context-hungry baseline. We isolate two failure modes of prior memories: single-level memory degrades sharply as the task set grows, and single-level concrete memories suffer catastrophic negative transfer, which contrast edges repair, lifting ScienceWorld from 78.7 to 96.7 within the same system.

**一句话**：提出 STRATA——一种三层结构化、结果锚定、可自维护的经验记忆图（原子技能/代码片段—任务工作流—元框架，带类型化边），让 LLM 智能体在测试时通过积累、检索与反哺经验自我进化。

痛点：现有 LLM 智能体的自演化记忆都是单层无类型池，把轨迹、蒸馏出的工作流、推理条目混在一起用嵌入相似度检索，既不遗忘也不去重，因而容易发生负迁移——召回表面相似但方向相反的经验并照搬其具体步骤，反而损害智能体。方法：STRATA 将经验组织成三层图（原子技能与代码片段 / 任务工作流 / 泛化元框架），用类型化边连接，并通过五种共享同一相似度几何的机制自维护：按操作与目标打分的多维相似度、从成功中结晶 procedure、从失败中结晶 pitfall 的类型化反射器、社区检测归纳元框架、压力触发且带关节点保护的垃圾回收、以及标记可混淆反向经验的对比边。结果：在 AppWorld、WebArena、ALFWorld、ScienceWorld 四个交互基准、两种冻结骨干、七个基线上取得最高平均分，同时延迟最低、环境交互步数最少。

> 🔗 **与课题**：① 工作流推理/任务分解：typed reflector 从成功轨迹中「结晶」出可复用的 procedure，把原子动作升格为任务工作流、再泛化为元框架，正是从任务经验中归纳工作流知识的过程。② Workflow→结构化表示：三层图 + 类型化边 + 社区检测诱导的元框架，是典型的把工作流组织为带依赖/类型语义的图结构的做法，与「processes+links」式结构化生成同构。③ 能力迁移：论文跨 AppWorld/WebArena/ALFWorld/ScienceWorld 四个环境复用同一记忆，并显式建模负迁移（contrast edges 标记方向相反的可混淆经验），直接对应源域→目标域迁移中的迁移保持率与负迁移问题。⑦ 评测：以平均分 + 延迟 + 环境步数三项同时衡量，提供了「能力提升不以代价换取」的多维评测协议。⑥ 训练/后训练：属免训练（test-time）自演化路线，可作为不依赖 SFT/RL 的对照思路。

💡 **启发**：对比边（contrast edges）机制可借用来解决 GEE→QGIS 迁移中最危险的情况：相似但语义相反的算子被误召回（如按属性筛选 vs 按位置筛选、投影定义 vs 投影变换），可为 QGIS 落地阶段加一层「反向经验标记」过滤；压力触发 + 关节点保护的经验剪枝，也可直接搬到工作流记忆库的维护上，避免记忆膨胀导致的检索噪声。

⚠️ **局限**：记忆与检索粒度停留在自然语言 procedure/pitfall 与代码片段层面，未验证到算子级 API 落地（如 QGIS processes+links 的依赖闭合图生成），三层抽象是否足以支撑严格可执行的图结构仍待检验。

🚨 **为什么必须重视**：该文与本研究③「跨平台/跨工具能力迁移」和①「工作流推理」正面撞车，且把「负迁移」明确列为可建模对象——这正是 GEE→QGIS 迁移最可能失败的模式，必须第一时间掌握其形式化定义与评测口径。其三层图（技能/工作流/元框架）几乎可直接映射到我们的 Workflow→结构化表示与 QGIS 落地两环，是可借用的结构骨架。若我们不做，类似记忆图方案会先一步被用作跨工具迁移的 baseline。

### ⭐⭐⭐⭐ RSIFlow: Adaptive Self-Improvement Workflows with an Evolving Meta-Agent
**7/10** · Huan Zhang、Mingju Chen、Dongxu Zhou、Can Lv、Sen Cui、Faguo Wu · arXiv · 2026-10-15 · [原文](https://arxiv.org/abs/2610.21791v1) · [PDF](https://arxiv.org/pdf/2610.21791v1)
*入选：工作流×工具推理*

> 📄 **摘要**：Large language model (LLM) agents have demonstrated strong capabilities in complex tasks, including code generation, tool use, and multi-hop question answering. Existing self-improvement methods enhance agent performance through model optimization, harness evolution, and executable artifact refinement, while recursive self-improvement (RSI) further extends optimization to the improvement mechanisms themselves. However, adapting self-improvement workflows to evolving performance bottlenecks while improving workflow orchestration through execution feedback remains a key challenge. We propose \textbf{RSIFlow}, a \textbf{R}ecursive \textbf{S}elf-\textbf{I}mprovement framework that integrates adaptive work\textbf{flow} orchestration with meta-agent capability evolution. RSIFlow diagnoses performance bottlenecks from task-agent trajectories and environmental feedback to dynamically select component-specific improvement workflows. The meta-agent then distills workflow outcomes into component-specific skills and cross-component principles, evolving its own harness to improve subsequent workflow orchestration. Experiments across six benchmarks and two backbone models show that RSIFlow achieves the SOTA average performance on all benchmarks. Ablation studies further demonstrate the contributions of adaptive workflow orchestration and meta-harness evolution. Code is available at https://github.com/1HUAN1/RSI-Flow.

**一句话**：提出 RSIFlow 递归自改进框架，用自适应工作流编排加元智能体能力演化，从任务轨迹与环境反馈中诊断瓶颈并蒸馏出可复用技能。

痛点：现有 LLM agent 自改进方法（模型优化、harness 演化、产物精修）难以随性能瓶颈变化而调整，也难以把执行反馈用于改进工作流编排本身。方法：RSIFlow 从任务-智能体轨迹与环境反馈中诊断瓶颈，动态选择组件级改进工作流，再由元智能体把工作流结果蒸馏为组件级技能与跨组件原则，演化自身 harness 以改进后续编排。结果：在六个基准、两个骨干模型上取得全部基准的 SOTA 平均性能，消融验证了自适应编排与元 harness 演化的贡献。

> 🔗 **与课题**：支撑环节①（自适应 workflow orchestration 即工作流推理中的任务分解与流程规划、按瓶颈动态选路）与环节⑥（把工作流产物蒸馏为技能、演化 harness，属于持续学习/自改进式后训练手段），并在环节⑦提供多基准评测协议与消融式错误分析。但它不做工具/算子 grounding（④），也不生成依赖闭合的 processes+links 结构（⑤），更没有跨平台/跨工具迁移保持率（③）的实证，因此只能作为通用方法支撑而非核心问题正面对标。

💡 **启发**：可把"执行反馈→瓶颈诊断→选择组件级改进工作流→沉淀为技能"的闭环借用为 QGIS 工作流生成能力的自适应后训练调度器，把幻觉算子、依赖不闭合、执行失败等信号当作诊断输入；元智能体蒸馏出的"跨组件原则"思路也可用于把 GEE 侧工作流知识抽象成可迁移的先验。

⚠️ **局限**：实验均在通用 agent 任务（代码生成、工具调用、多跳QA）上，未验证跨平台跨工具迁移，且 harness 迭代演化带来多轮执行开销。

### ⭐⭐⭐⭐ EvolvingBrain: An Adaptive Skill System for Multi-modal Agents Self-Evolution in Open Worlds
**7/10** · Runxuan Liu、Jingqi Shi、Baoxin Wang、Honghong Zhao、Haoyuan Xu、Yueqing Sun · arXiv · 2026-10-14 · [原文](https://arxiv.org/abs/2610.20786v1) · [PDF](https://arxiv.org/pdf/2610.20786v1)
*入选：RL×LLM方法*

> 📄 **摘要**：Multi-modal agents have made significant progress in interacting with open worlds. However, their ability to self-evolve remains limited. Supervised fine-tuning enables imitation but not active experience organization, while outcome-based reinforcement learning promotes exploration yet underuses intermediate trajectory information. Therefore, we propose EvolvingBrain, which uses an adaptive skill system as the brain for agent self-evolution, consisting of two following components. Stratified Skill Self-Evolution: extracts Procedural Patterns and Problematic Patterns from model-specific trajectories, summarizes experience by generating skills, and evolves through multiple interactions with the open world, ultimately forming a Stratified Skill Architecture consisting of Domain, Plan, and Action/Trap Skills, which provides the agent with a multi-granularity knowledge repository and a novel evolution approach. State-Aware Adaptive Execution: summarizes long-horizon interactions into Structured Abstractive Memory and uses it to guide the State-Aware Skill Fusion Strategy, enabling the agent to utilize knowledge according to its current state. Experiments on VAB-Minecraft and DiscoveryWorld demonstrate that EvolvingBrain improves success rates on open-world tasks and exhibits generalization capabilities. Our code is provided in the supplementary materials and will be publicly released in the camera-ready version.

**一句话**：提出 EvolvingBrain，用从轨迹中抽取的分层技能体系（Domain/Plan/Action/Trap）与状态感知记忆，让多模态智能体在开放世界中自我进化。

痛点：SFT 只能模仿、无法主动组织经验，outcome-based RL 又浪费了中间轨迹信息。方法：从模型自身轨迹中抽取程序性模式与问题性模式，生成技能并逐层沉淀为 Domain/Plan/Action/Trap 分层技能库，同时把长程交互摘要成结构化记忆以驱动状态感知的技能融合。结果：在 VAB-Minecraft 与 DiscoveryWorld 上提升开放世界任务成功率并展现泛化能力。

> 🔗 **与课题**：支撑环节①与②为主：Domain/Plan/Action 三层技能本质上就是"任务→子任务→原子动作"的多粒度工作流分解，与课题的 Workflow Reasoning（任务分解、步骤规划、依赖组织）同构；'结构化摘要记忆'对应②中把推理过程沉淀为可复用的结构化表示。此外它还覆盖⑥：把技能库当作不依赖权重更新的"持续学习/后训练替代方案"，可与 DAPT/SFT/LoRA 做机制对照。评测上提供成功率与跨任务泛化指标，可部分参考⑦。但论文不含工具/算子 grounding，也没有跨平台（GEE→QGIS）或跨工具迁移的实证，因此属于通用方法层支撑，未直接命中核心问题。

💡 **启发**：可借鉴其"从失败轨迹反向抽取 Problematic/Trap 模式"的做法，针对 QGIS 落地环节构建"幻觉算子/非法参数"陷阱技能库，用于抑制幻觉算子率与失败链路；分层技能（Plan 层对应 workflow 图、Action 层对应 operator）也可直接映射为 GEE→QGIS 的中间表示候选。

⚠️ **局限**：评测限于 Minecraft/DiscoveryWorld 两类游戏化环境，技能体系与结构化记忆的有效性未经真实工具链（API/代码/GIS）验证，泛化声明偏弱。

### 🔥 ⭐⭐⭐⭐ MLExpert: Towards a Generalist Agentic Model for Autonomous Machine Learning Engineering
**8/10** · Shangheng Du、Jinxin Shi、Shuaiyu Zhang、Yiming Wu、Junpeng Zhao、Shiyang Feng · arXiv · 2026-10-15 · [原文](https://arxiv.org/abs/2610.22344v1) · [PDF](https://arxiv.org/pdf/2610.22344v1)
*入选：能力迁移*

> 📄 **摘要**：Large language models (LLMs) are expanding from assisting scientific research and engineering to autonomously developing and improving AI systems, advancing AI for AI (AI4AI) as a pathway toward recursive self-improvement (RSI). Workflow-driven machine learning engineering (MLE) systems provide a practical path toward this pursuit through complex orchestration that manages long-horizon experimentation, while recent MLE systems adopt model-directed interaction, allowing models to autonomously organize experiments and adapt optimization strategies based on execution feedback. However, feedback from each experiment reflects several preceding decisions, and a long MLE run contains many such costly experiments. Training must therefore select useful supervision from long interaction trajectories and learn from intermediate outcomes. We propose a post-training method for autonomous long-horizon MLE optimization and apply it to train MLExpert, a 35B Mixture-of-Experts agentic model. We design the Kaggle-MLE Factory to construct executable tasks and an interaction harness for model-directed experimentation. Hierarchical agentic SFT transfers general tool-use and coding capabilities to MLE through outcome-guided supervision. Windowed Interaction RL (WIRL) treats the multi-turn decisions between successive experiment results as an execution window and assigns it a shared outcome-based reward. Asynchronous collection and policy correction support policy updates before the trajectory ends. On MLE-Bench Lite, MLExpert improves the average medal rate of the base model from 37.9% to 72.7%, achieving performance comparable to larger frontier models such as Kimi-K3 and GLM-5.3. Further experiments show that MLExpert improves performance on NatureBench Lite, agent scaffold optimization, and algorithm optimization, suggesting that the learned optimization capability generalizes to other tasks.

**一句话**：提出 MLExpert（35B MoE 智能体模型）及其后训练流程——层级化 agentic SFT 加窗口化交互强化学习（WIRL），用于长时程自主机器学习工程（MLE）。

痛点：长时程 MLE 智能体的单条实验反馈耦合了此前多个决策，长轨迹中大量昂贵实验导致监督信号稀疏、难以挑选有效训练信号。方法：作者搭建 Kaggle-MLE Factory 构造可执行任务与交互 harness，用 outcome-guided 的层级 agentic SFT 把通用工具使用与代码能力迁移到 MLE，并提出 Windowed Interaction RL，把相邻实验结果之间的多轮决策视为一个执行窗口并赋共享结果奖励，配合异步采样与策略纠正。结果：形成了一条从可执行任务构造、能力迁移式 SFT 到长时程信用分配的完整 agentic 后训练范式。

> 🔗 **与课题**：本论文在多个环节上高度对照：环节③（能力迁移）——其核心主张正是把通用 tool-use 与 coding 能力通过层级 agentic SFT 迁移到 MLE 这一新领域，是典型的"源域→目标域"能力迁移实证，与 GEE workflow reasoning→QGIS grounding 的迁移结构同构；环节①（工作流推理）——全文以 workflow-driven MLE orchestration 为骨架，研究长时程任务分解与实验编排；环节⑥（训练/后训练）——给出 outcome-guided 层级 SFT + WIRL 两段式后训练配方，并处理长轨迹监督筛选与中间结果学习；环节⑦（评测）——Kaggle-MLE Factory 的可执行任务与 harness 本质是一套"生成即执行"的评测协议，可直接类比 QGIS 图的可执行率/依赖闭合率评测；环节⑤的结构化图生成对应其"多轮决策序列"的编排表示。唯一缺口是没有 operator grounding 的显式落地层与 GIS 语境。

💡 **启发**：可直接偷两点：一是"执行窗口共享结果奖励"——把整张生成的 processes+links 图当作一个执行窗口，用可执行性/依赖闭合作为共享奖励，绕过中间步骤标注难题；二是 Kaggle-MLE Factory 式的"可执行任务工厂+交互 harness"，可复刻为 QGIS 可执行任务工厂来做 DAPT/SFT 数据与评测。

⚠️ **局限**：MLE 域的奖励（排行榜分数）远比 GIS 工作流更稠密、更客观可量化，其 WIRL 奖励设计与监督筛选策略迁移到 QGIS 结构化图时需重新校准；且 35B MoE 的规模与本研究可用算力可能存在量级差距。

🚨 **为什么必须重视**：它与本课题在科学问题上几乎同构：都是"在一个 workflow 域上训练模型、把通用工具/代码能力迁移到新域并保证落地可执行"，属于潜在竞品动向，越早掌握其迁移配方越有利。其层级 agentic SFT 的"通用能力→领域能力"迁移路径，可直接作为 GEE→QGIS 迁移实验的对照设计与训练基线。WIRL 对长时程多轮决策的信用分配方案，是当前 workflow 图生成训练中稀缺且可直接借用的方法组件。

### ⭐⭐⭐⭐ MAI-Gym: An Open All-in-One Platform for GUI Agent Evaluation and RL Training across Mobile and Computer Environments
**7/10** · Panrong Tong、Quyu Kong、Pengxiang Li、Tianyu Xia、Hanzhang Zhou、Lei Wang · arXiv · 2026-10-14 · [原文](https://arxiv.org/abs/2610.20939v1) · [PDF](https://arxiv.org/pdf/2610.20939v1)
*入选：RL×LLM方法*

> 📄 **摘要**：Online reinforcement learning (RL) with verifiable rewards has driven rapid progress in mathematics, coding, and tool use, but scaling this success to GUI agents remains challenging due to the high cost of interactive environments and the scarcity of realistic training tasks. We introduce MAI-Gym, an open all-in-one platform that unifies GUI agent evaluation, data collection, and online RL training across mobile, computer, and web environments. Through a shared rollout pipeline, MAI-Gym ensures consistent agent behavior across evaluation and training, supports ten established benchmarks, and scales to 20,000 parallel environment instances. Beyond scalable infrastructure, MAI-Gym enables automated synthesis of diverse GUI applications and challenging tasks, including resettable mocked apps and coherent cross-app worlds with execution-validated task verifiers. Using MAI-Gym, we train MAI-Gym-9B, a unified 9B agent for mobile and computer use, achieving state-of-the-art performance among open GUI agents under 10B parameters: 78.4% on MobileWorld and 76.2% on OSWorld-Verified. Importantly, RL in a mocked train-ticketing app transfers to its real-world counterpart, improving task success on a phys- ical phone from 28.8% to 48.1%. We release the framework, synthesis skills, mocked apps, 2,000 verified tasks, and the model checkpoint to support repro- ducible research and further advances in scalable GUI agent training.

**一句话**：提出 KnowGPO：把深度搜索智能体回答所需信息分解为原子知识条件，以"已满足条件子集"作为轨迹状态做分组比较，并用相邻步知识增量作为环境锚定的过程奖励来优化搜索 agent。

痛点：深度搜索 agent 的长程多轮交互中，结果型 RL（如 GRPO）只有共享的终局奖励，而现有过程监督方法把信用锚定在表层轨迹状态或模型内部信号上，在观测异构、检索上下文长而嘈杂时不可靠。方法：KnowGPO 将每个 query 所需信息分解为原子知识条件，用满足条件的子集表示每步轨迹状态，把知识状态相同的轨迹分组做组内比较，并以相邻步的知识增量作为过程奖励。结果：在 Xbench、BrowseComp-ZH、GAIA 上稳定超过 outcome-only（GRPO）与过程监督基线（GiGPO、IGPO）3.8–4.2 分，8B 模型逼近或超过多数 32B 开源系统。

> 🔗 **与课题**：主要支撑环节⑥（训练/后训练中的 RL 手段）：它给出一种面向长程多轮工具型 agent 的步骤级信用分配/过程奖励方案，可解释"Workflow Reasoning 的步骤级监督信号从何而来"。部分支撑⑦（评测）：其组内比较与增量奖励实质是一种过程级评测/错误定位协议；也对①（任务分解）有间接支撑——把复杂任务拆成原子条件正是任务分解的一种形式化。但它不做工具/算子 grounding（④）、不做结构化依赖图生成（②⑤），也不做跨域跨平台迁移（③），场景是搜索工具调用而非 GIS 工作流。由于论文绑定 tool/agent 场景，不属于"纯 RL 算法改进"的 0-2 档，归于 5-7 的通用支撑方法档。

💡 **启发**：可把"原子知识条件 + 已满足子集作为状态抽象 + 同状态分组比较 + 增量过程奖励"这一范式平移到 GIS 工作流：把 workflow 步骤依赖抽象成原子子目标/依赖条件，从而在无显式 L3 语义中间层的情况下获得步骤级过程奖励信号，直接服务于 Workflow Reasoning 训练。

⚠️ **局限**：状态抽象依赖预先分解好的原子知识条件，对依赖关系无法枚举、条件边界模糊的开放域工作流（如 GIS 流程）如何自动构造该分解并未解决，迁移成本需自行验证。
