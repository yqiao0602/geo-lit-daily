### 🔥 ⭐⭐⭐⭐ RA-MoWE: Workflow-Affinity Embeddings for Query Clustering and Agentic Workflow Generation
**8/10** · Qi Cheng、Shengyu Chen、Wei Cheng、Yiqun Xie、Haoyu Wang、Haifeng Chen · arXiv (Cornell University) · 2026-10-06 · [原文](https://doi.org/10.48550/arxiv.2610.07851)
*入选：工作流×工具推理*

> 📄 **摘要**：Agentic workflows enable large language models (LLMs) to solve complex tasks by coordinating reasoning, tool use, and verification. However, a workflow optimized for an entire task collection can overlook differences in the reasoning strategies that individual queries need, while searching for a new workflow for every query repeats costly optimization. To address this tradeoff, we introduce RA-MoWE, a framework that uses workflow-affinity embeddings to cluster queries and guide the generation of reusable expert workflows. Each embedding records how well a fixed set of reference workflows solves a query, revealing similarities in which reasoning strategies are effective. RA-MoWE uses each cluster's queries and average embedding to initialize and refine a specialized workflow through execution feedback. An embedding encoder predicts these embeddings from query text, allowing new queries to select a generated expert without first executing the reference workflows. On a 300-query test set drawn from four benchmarks spanning mathematics, science, and programming, RA-MoWE improves average task score by 4.04 percentage points over selecting among the reference workflows, while using 27.7% fewer language-model calls at inference.

**一句话**：提出 RA-MoWE，用「工作流亲和度嵌入」对查询聚类并据此生成可复用的专家工作流，再用嵌入编码器从查询文本直接预测亲和度以选择工作流。

痛点：为整个任务集合优化一个统一 agentic workflow 会忽略单条查询所需的推理策略差异，而为每条查询单独搜索工作流又代价高昂。方法：让每条查询在一组固定参考工作流上执行，把「哪些参考工作流能解它」编码成 workflow-affinity embedding，据此聚类查询，并以簇内查询与平均嵌入初始化+执行反馈迭代精化出专用工作流；再训练编码器从查询文本预测该嵌入，使新查询无需实际执行参考工作流即可选到合适的专家工作流。结果：在覆盖数学、科学、编程四个基准的 300 条测试集上，平均任务分比「在参考工作流中择优」高 4.04 个百分点，推理时 LLM 调用减少 27.7%。

> 🔗 **与课题**：主要支撑环节①（GIS Task→Workflow）：论文的核心正是把任务/查询映射到工作流，并研究「任务差异 → 推理策略差异」这一工作流选择与分解问题，与我们 Route-2 中「任务分解、步骤规划」的部分同构。其次支撑环节②（Workflow→结构化表示）：它显式地把查询与一组工作流之间的匹配关系编码为向量化的结构化表征，并以此作为生成/精化工作流的中间表示，这与我们想要的「workflow 结构化表示」思路可迁移。第三涉及环节⑤/④的间接支撑：专家工作流由参考工作流（含 tool use）按照执行反馈精化生成，属于「结构化 workflow → agent 可执行图」的自动生成范式。第四涉及环节⑦（评测）：用任务分 + LLM 调用次数双指标衡量工作流质量与效率，可直接借用为工作流推理质量/落地可用率的评测协议。此外，其「先用参考工作流探测、再训练编码器预测」的两阶段做法，本质上是一种免执行的迁移/代理预测机制，可类比我们 GEE→QGIS 场景下用少量探测推断迁移后可用的工作流类型。

💡 **启发**：可直接借用两点：(1) 用「固定参考工作流集合上的执行结果」作为任务的结构化嵌入（affinity embedding），把「某任务需要什么样的 workflow」变成可预测的向量，从而免执行地路由新任务——可迁移为「GEE 学到的工作流知识 → QGIS 工作流选择」的免执行预测器；(2) 用簇级平均嵌入 + 执行反馈迭代精化专家工作流的训练/后训练范式（可视为一种工作流级的 SFT/偏好信号），可作为我们结构化 QGIS 图生成的生成-反馈闭环模板。

⚠️ **局限**：实验仅限数学/科学/编程文本基准，工作流是 LLM 代理的推理-工具调用链而非真正的算子图，其「参考工作流」是预置的少量候选，聚类与嵌入的优越性是否在开放、大规模、强依赖约束（如 GIS processes+links）的图生成上成立尚未验证。

🚨 **为什么必须重视**：它直接撞在我们 Route-2 的核心问题上：让模型学到「任务→工作流」的推理能力并迁移复用，且给出了免执行的迁移预测机制与「任务分 + 调用次数」的评测协议，属于同赛道竞品级工作，方法可被直接借用或必须作为对比基线。若我们还在用单一 workflow 或逐任务搜索，本文的 query-level workflow 差异化聚类会立即显示出效率与效果优势。其两阶段「探测-嵌入-预测」管线若被移植到 GEE→QGIS 的跨平台场景，很可能抢先占据我们想做的能力迁移落地路径。

### 🔥 ⭐⭐⭐⭐ OOPMAS: Object-Oriented Multi-Agent Systems for Query-Level Workflow Generation
**8/10** · Qi Cheng、Shengyu Chen、Wei Cheng、Yiqun Xie、Xiaowei Jia、Haoyu Wang · arXiv (Cornell University) · 2026-10-06 · [原文](https://doi.org/10.48550/arxiv.2610.07787)
*入选：工作流×工具推理*

> 📄 **摘要**：Multi-agent systems (MAS) powered by large language models have shown strong performance across code generation, mathematical reasoning, and question answering. However, existing methods for automating MAS design mostly operate at the task level, producing a single fixed workflow per benchmark that is applied uniformly to all queries. This assumption fails under realistic conditions. Query difficulty varies widely within a task, and real-world workloads mix heterogeneous task types. We introduce OOPMAS, a training-free framework that generates both the agent set and the coordination workflow at the granularity of individual queries. Agents are represented as object-oriented class definitions with dedicated roles, tools, and persistent state, and workflows are expressed as executable main functions over these agent objects. A dynamic skill library accumulates structured lessons from execution feedback across optimization rounds, enabling in-context improvement without any gradient updates or fine-tuning. On a mixed-task benchmark of queries spanning code, math, and QA, OOPMAS achieves 89.6% accuracy, outperforming the strongest baseline by 18.1 percentage points. A model-swap study across four LLM backbones shows consistent scaling, reaching 92.4% with the strongest model.

**一句话**：提出免训练的 OOPMAS 框架，以查询为单位生成由面向对象智能体类与可执行 main 函数工作流组成的多智能体系统，并用动态技能库从执行反馈中做上下文内改进。

痛点：现有自动化多智能体系统（MAS）设计多停留在任务级，一个 benchmark 固定一套工作流并统一应用于所有查询，无法适应查询间难度差异与真实负载中混合任务类型的现实。方法：OOPMAS 在单查询粒度上同时生成智能体集合与协作工作流——智能体表示为带角色、工具与持久状态的面向对象类，工作流表示为作用于这些智能体对象的可执行 main 函数，并通过跨优化轮累积结构化经验教训的动态技能库实现无梯度、免微调的 in-context 改进。结果：在覆盖代码、数学、QA 的混合任务基准上达到 89.6% 准确率，超最强基线 18.1 个百分点，跨四个 LLM backbone 的 model-swap 实验显示一致 scaling，最强模型达 92.4%。

> 🔗 **与课题**：支撑环节①（工作流推理/任务分解）：论文核心正是把"每任务一套固定流程"改为"每查询一套流程"，是对任务分解与步骤规划粒度的直接研究，可类比迁移到 GIS Task→Workflow 的细粒度工作流推理。支撑环节②⑤（结构化表示与图生成）：智能体以类定义（角色/工具/状态）、工作流以可执行 main 函数表示，本质上是把自然语言工作流编译为结构化、依赖可执行、可运行的程序／图结构，与 QGIS processes+links 图的依赖闭合生成思路同源。支撑环节⑥（训练/后训练）：动态技能库从执行反馈中累积结构化教训、无需梯度更新即可提升，是可移植到 QGIS 场景的免训练适配／持续改进机制候选解释框架。支撑环节⑦（评测）：混合任务基准 + 跨四个 backbone 的 model-swap 评估，为工作流质量与跨模型迁移保持率（transfer retention）提供了可借用的评测协议范式。未覆盖环节③④：论文完全不涉及跨平台（GEE→QGIS）能力迁移与算子级 grounding，也无 GIS 语境，故此两环节需自行补足，本文更适合作为方法论对比基线。

💡 **启发**：把"动态技能库 + 执行反馈"的免训练 in-context 改进机制整体搬到 QGIS 图生成上：用执行失败与幻觉算子的反馈自动累积可复用的 QGIS 操作经验，无需微调即可提升落地可用率。另外 query-level（而非 task-level）的工作流生成粒度提示我们在评测 workflow reasoning 时应按查询难度分层，而非一个数据集一套流程。

⚠️ **局限**：其工作流是面向多智能体协作的调度结构而非面向数据/算子依赖的处理 DAG，且没有任何工具 grounding 与跨平台迁移验证，迁移到 QGIS 时需重新论证表示能否承载 processes+links 的依赖闭合。

🚨 **为什么必须重视**：该文与课题"工作流推理 + 结构化工作流生成"的核心科学问题直接撞车：它已把 workflow generation 推进到查询级并落到可执行结构化表示，若不在相关工作中定位并对比，本课题在"结构化工作流生成"上的新颖性会被明显稀释。其免训练技能库机制是零算力即可移植的适配手段，可直接用于 QGIS operator grounding 实验，快速构建 baseline。同时它的跨 backbone model-swap 评估为我们的 transfer retention（迁移保持率）指标设计提供了现成范式，属于必须立即精读并考虑设为对比基线的竞品动向。

**▸ 建议：精读**

### ⭐⭐⭐ VulnTACT: Predicting ATT&CK for ICS Tactics and Techniques from Vulnerability Information Using Domain-Adapted Large Language Models
**6/10** · Hui-Seok Yang、Seong-Su Yoon、Ieck-Chae Euom · Journal of Information Security and Applications · 2026-10-07 · [原文](https://doi.org/10.1016/j.jisa.2026.104664)
*入选：能力迁移*

> 📄 **摘要**：Industrial control systems (ICS) require vulnerability prioritization that reflects adversarial behavior and operational consequences, particularly when patching is constrained by safety and availability requirements. However, existing vulnerability-to-ATT&CK approaches are largely designed for general IT environments and often rely on direct CVE-to-technique mapping, providing limited support for ICS-specific context, multi-label inference, and downstream operational impacts. This study proposes VulnTACT, a lightweight framework for predicting MITRE ATT&CK for ICS tactics and techniques from heterogeneous vulnerability evidence. Rather than directly mapping vulnerability descriptions to ATT&CK labels, VulnTACT performs five ICS-aware reasoning steps covering vulnerability type, enabled functionality, exploitation technique, affected object, and adversarial tactic. The intermediate results and retrieved evidence are synthesized into category-specific candidates for exploitation techniques, primary impacts, and secondary impacts, followed by a ranked multi-label prediction. The reasoning structure is informed by MITRE’s CVE Mapping Methodology, while retrieval and QLoRA-based domain adaptation provide vulnerability-specific evidence and alignment with recurring ICS terminology and cross-source security semantics. Experiments using a 2024 validation set, a temporally separated 2025 test set, and 59 CTI-derived cases show improvements of approximately 7–12 percentage points over the strongest baseline across ranking metrics. Ablation results confirm the complementary contributions of retrieval, domain adaptation, and structured five-step reasoning. VulnTACT therefore supports resource-efficient and traceable vulnerability-to-ATT&CK mapping for threat-informed prioritization and compensating-control selection in patch-constrained ICS environments.

**一句话**：提出 VulnTACT 框架，用检索增强+QLoRA 域适配的轻量 LLM，把异构漏洞证据经五步 ICS 感知推理链预测为 MITRE ATT&CK for ICS 的战术/技术多标签。

痛点：现有 CVE→ATT&CK 映射方法面向通用 IT 环境，依赖直接映射，无法处理 ICS 语境、多标签推理与下游运行影响。方法：不直接映射标签，而是执行漏洞类型→可利用功能→利用技术→受影响对象→对抗战术五步推理，合并中间结果与检索证据生成技术/主次影响的类别候选并做排序多标签预测，推理结构参考 MITRE CVE Mapping Methodology，用 QLoRA 做领域适配。结果：在 2024 验证集、时间隔离的 2025 测试集与 59 个 CTI 案例上比基线提升约 7–12 个百分点。

> 🔗 **与课题**：支撑环节①：把扁平分类改写为固定的五步推理分解（漏洞类型→功能→技术→对象→战术），与 GIS Task→Workflow 的任务分解/步骤规划同构，可作为“显式推理链替代端到端映射”的通用证据。支撑环节②：中间推理结果与检索证据被合成为类别候选再排序，是结构化中间表示→目标标签的生成范式。支撑环节③：从通用 IT 安全语义到 ICS 专有术语与跨源语义的域适配，属于源域→目标域的迁移实证（类似 GEE→QGIS 的术语/算子对齐需求）。支撑环节⑥：QLoRA 域适配属 PEFT/DAPT 手段，可类比用领域语料对齐目标平台算子库。支撑环节⑦：时间隔离测试集+CTI 案例的评测协议可借鉴。不涉及④⑤的 processes+links 图生成与自由工作流依赖组织，因此不进 8-10 档。

💡 **启发**：可借用“固定推理步骤链 + 检索证据 → 类别候选 → 排序多标签”的两阶段结构：先让模型产出中间推理候选（对应 QGIS operator 候选），再做排序与依赖闭合校验，比直接生成 processes+links 更可控、更易失败归因；其“推理结构由权威方法论（MITRE 映射方法）约束”的做法，可换成由 QGIS 官方 operator/参数规范约束解码。

⚠️ **局限**：推理链是领域专家预定义的固定五步模板，非模型自主规划，也不产出显式依赖图；任务是分类而非可执行结构生成，跨到 GIS workflow 生成时需自行验证迁移有效性。

### ⭐⭐⭐ WOVEN: Weaving Visual World Modeling into Multimodal LLMs
**6/10** · Zheyu Fan、Yue Zhang、Mingkai Deng、Kangrui Wang、Qineng Wang、Canyu Chen · arXiv · 2026-10-08 · [原文](https://arxiv.org/abs/2610.12417v1) · [PDF](https://arxiv.org/pdf/2610.12417v1)
*入选：能力迁移*

> 📄 **摘要**：Multimodal large language models (MLLMs) struggle with spatial, embodied, physical, and temporal reasoning. We hypothesize that these failures reflect a shared deficit in visual transition reasoning, and test whether this capability can serve as a shared training primitive, one that different models can learn from different supervision sources and reuse across different tasks, with a systematic training recipe. Existing benchmarks document these deficits separately but do not support controlled comparisons across scenes, actions, and reasoning operations. We therefore introduce WOVEN, a training source and benchmark for visual transition reasoning that organizes transition supervision by scene, action, and reasoning type, using diverse, realistic rollouts from video-pretrained generative models: 36,076 examples across 20 scene types, 5 action types, and 8 reasoning types. We first evaluate 38 frontier MLLMs (e.g., GPT-5.4 and Qwen3-VL-235B-A22B) and find a substantial and systematic deficit: even the strongest models fall far below humans, and the failures recur across model families and persist with scale. We then train MLLMs at multiple scales on WOVEN and find that they learn a shared capability that transfers broadly: training subsets of only about 2,000 items each collectively improve 22 of 26 external benchmarks by up to 27.3 percentage points, and WOVEN data can replace 30-50% of a task's own training data with comparable accuracy. Controlled comparisons further yield a training recipe for visual world modeling, validated prospectively on held-out benchmarks: select supervision by the reasoning operation it teaches rather than by the actions, scenes, or domains it shows, and prefer larger changes to the visual state for robustness. Our work establishes visual transition reasoning as a reusable foundation for systematic visual world-model training in MLLMs.

**一句话**：该论文提出WOVEN，一个视觉转换推理的训练源与基准，并实证发现训练MLLM学习该共享能力后可跨多个外部基准迁移。

多模态大模型在空间、具身、物理、时间推理上存在共同缺陷，论文假设其源于视觉转换推理能力不足。为此构建WOVEN数据集（36k样本，覆盖20种场景、5种动作、8种推理类型），评估38个前沿MLLM发现系统性缺陷，并训练多个规模模型，证明约2000条子集训练即可提升22/26个外部基准，最高+27.3pp，且可替代30-50%任务自身训练数据。

> 🔗 **与课题**：支撑环节③能力迁移（源域→目标域迁移的实证研究）和环节⑥训练/后训练（共享训练原语、迁移学习配方），以及环节⑦评测（基准设计与跨任务迁移保持率测量）。但它迁移的是视觉转换推理能力，而非workflow reasoning或tool/operator grounding，与GIS workflow推理到QGIS落地的核心链条仅有方法论类比，无直接内容重叠。

💡 **启发**：可借鉴其“共享训练原语”设计：将workflow推理能力作为可跨任务复用的训练目标，用少量高质量数据（如2000条）激发迁移；其跨外部基准测量迁移保持率的协议可用于评估GEE→QGIS工作流知识迁移效果。

⚠️ **局限**：研究的是多模态视觉转换推理，不涉及workflow reasoning、工具落地或结构化图生成，迁移结论不能直接外推到GIS工作流推理能力迁移。

### ⭐⭐⭐ Internalizer: Portable Context-to-Parameter Mapping for Very Large Language Models
**6/10** · Peter Devine、Nick Ryan、Benjamin Sirb、Alex Chiocchi · arXiv · 2026-10-08 · [原文](https://arxiv.org/abs/2610.11715v1) · [PDF](https://arxiv.org/pdf/2610.11715v1)
*入选：领域×任务*

> 📄 **摘要**：Hypernetworks that map a context directly to a LoRA adapter let a large language model carry that context in its weights, but prior work has demonstrated them only on base models of up to 14 billion parameters. We present the Internalizer, a state-of-the-art, portable Context-to-Parameter Mapping hypernetwork that generates document-specific LoRA adapters for the frozen 284B-parameter DeepSeek v4 Flash, a target two orders of magnitude larger than in any previous work. Most of its parameters live in a model-agnostic trunk with only thin entry and exit layers per base model, so it trains cheaply against small models before being ported to the large one. On unseen documents of up to 4096 tokens, the generated adapters reach 84.9% top-1 and 97.8% top-5 teacher-forced accuracy against 63.4% and 83.5% for the base model, with nothing in the context window but a three-word instruction. ⚠️ **局限**：迁移证据仍限于同族 SQL/数据库交互任务，跨范式（GEE→QGIS、NL→桌面算子 API）的外推有限；且方法高度依赖可低成本构建的隔离可执行环境与隐藏 oracle，GIS 桌面软件场景中环境构建成本与可观测性更差。

### ⭐⭐⭐ Use and Disuse: Intent-Structured Experience Consolidation for Memory and Learning in LLM Agents
**6/10** · Xiangyi Zeng、Baihang Liu、Xutong Wang、Ze Jin、Yunpeng Li、Qixu Liu · arXiv · 2026-10-08 · [原文](https://arxiv.org/abs/2610.12124v1) · [PDF](https://arxiv.org/pdf/2610.12124v1)

> 📄 **摘要**：The evolution of Large Language Model agents from single-task execution to long-term autonomous operation highlights the critical challenge of transforming continuous experiences into reusable knowledge. Hippocam draws inspiration from two characteristics of human memory: cognitive processes selectively maintain information relevant to current goals, while long-term memories form gradually through repeated consolidation. Accordingly, Hippocam structures an agent's ongoing work as nested intents. The active context remains centered on the current intent, while completed intents are consolidated into the task-relevant outcomes and state needed for subsequent work, rather than carrying forward their full working details. **一句话**：提出 Hippocam——一个受人类记忆启发的层级式记忆与持续学习架构，用嵌套 intent 组织 agent 工作并对旧经验做递归前缀压缩，使长期未用经验逐渐抽象化、常用经验被反复强化更新。

💡 **启发**：可借用其“嵌套 intent + 递归前缀压缩”做法，把 GEE 工作流轨迹按 任务意图→子步骤→算子 分层压缩存储，只保留可迁移的工作流抽象而非平台专属 API 细节，作为 GEE→QGIS 迁移的训练/经验回放语料构建策略。

⚠️ **局限**：纯 agent 记忆/持续学习架构，无跨工具、跨平台迁移与算子 grounding 的实证，也未在代码/工作流生成任务上评测，对本课题只能作为持续学习机制的参考而非可对比基线。
