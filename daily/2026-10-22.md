### ⭐⭐⭐ Relative Representations Enable Portable White-Box Monitoring Across Language Models
**6/10** · Tim Bakker、Christos Louizos · arXiv · 2026-10-20 · [原文](https://arxiv.org/abs/2610.28366v1) · [PDF](https://arxiv.org/pdf/2610.28366v1)
*入选：能力迁移*

> 📄 **摘要**：Independently trained autoregressive language models often acquire similar capabilities, but it remains unclear whether their internal representations organize behaviorally relevant information in compatible ways. We show that models do in fact organize information similarly by using specific behavioral probes that operate on compatible representations. This unlocks portable white-box monitoring: a probe developed and validated on one model can be reused when the model changes, without requiring labeled target data. To overcome incompatible native activation coordinates, we express each example through its angular distances to a shared set of anchors. We introduce a global anchored construction that summarizes information from all transformer layers and removes model-specific layer selection, so the same frozen probe can be straightforwardly applied to another model. We evaluate cross-model probe transfer across monitoring tasks on trivia datasets, safety monitoring, and mathematical reasoning. On average, transferred global anchored probes preserve at least 85% of same-model probe AUROC over chance. Anchored probes also support transfer to related datasets, remain robust across model scale and prompt changes, and retain performance better than standard probes after model updates. Transfer is nevertheless task- and target-dependent and can fail even when the monitored property remains strongly decodable in the target model. Overall, global anchoring reveals substantial task-relevant compatibility across independently trained models and provides a practical basis for portable white-box monitoring.

**一句话**：论文提出用「相对表示」——即每个样本相对于一组共享锚点的角度距离——构造全局锚定探针，使在一个语言模型上训练的冻结探针可以不加改动地迁移到另一个独立训练的模型上，用于白盒监测。

痛点：不同独立训练的 LLM 虽然获得相似能力，但其原生激活坐标不兼容，导致白盒探针难以跨模型复用。方法：把激活表示成对共享锚点集合的角度距离（相对表示），并提出全局锚定构造汇总所有 transformer 层的信息、去除模型特定的层选择，使同一冻结探针可直接作用于另一个模型、无需目标域标注。结果：在 trivia、安全监测、数学推理三类任务上，迁移后的全局锚定探针平均保留至少 85% 的同模型 AUROC 增益，并在模型规模、prompt 变化和模型更新下保持稳健；但迁移效果仍依赖任务与目标模型，且可能在目标模型仍能强解码被监测属性时失效。

> 🔗 **与课题**：主要对应环节③（能力迁移）：它给出的是「源模型→目标模型」的表示层迁移实证与失败分析。对课题的间接价值在于：为「工作流知识是否在模型内部以可迁移形式存在、迁移保持率如何度量」提供一种无需目标域标注的探测式度量手段。它不是 workflow reasoning（①）、结构化生成（②⑤）、operator grounding（④）或训练后训练（⑥）的研究，也不直接给出评测协议（⑦），因此只作为迁移机制/度量的候选解释框架进入 5-7 档。

💡 **启发**：可借用「锚点角度距离 + 全局层汇总」的思路，把 GEE 域与 QGIS 域的中间表示投到同一锚点空间，做一个跨平台「迁移保持率」的白盒诊断量；其「表示高度可解码但探针迁移仍失败」的现象提醒：迁移保持率不能只用探针可解码性替代行为层面的 grounding 成功率。

⚠️ **局限**：探针迁移度量的是内部信息的可解码性与坐标兼容性，而非行为层面的能力迁移；论文自陈迁移任务与目标依赖强、会失败，因此不能直接当作 workflow 知识迁移的等价证据。

### ⭐⭐ FALCA: Falsification-Aware Reinforcement Learning with Hierarchical Credit Assignment for Long-Horizon Deep Search Agents
**5/10** · Zijun Dou、Kun Luo、Chaofan Li、Shuqi Lu、Zheng Liu · arXiv · 2026-10-20 · [原文](https://arxiv.org/abs/2610.28361v1) · [PDF](https://arxiv.org/pdf/2610.28361v1)
*入选：RL×LLM方法*

> 📄 **摘要**：Long-horizon deep search requires LLM agents to iteratively decompose complex information needs, gather evidence from external sources, and maintain a reliable research state under multiple constraints. A central challenge is that early mistakes can be amplified over the search trajectory: agents may anchor on an incorrect candidate, collect partially supporting evidence, overlook contradictions, and accumulate errors that misguide subsequent reasoning. We propose FALCA, a falsification-aware framework that formulates deep search as a propose-falsify process. FALCA adopts a collaborative Searcher-Falsifier architecture, where the Searcher proposes candidate answers or sub-answers, while independent Falsifiers actively seek counterevidence, check unmet constraints, identify conflicts, and produce concise falsification reports for research-state revision. To strengthen this loop, we introduce falsification-aware training, combining SFT warmup on falsification trajectories with agentic RL based on parallel rollouts and hierarchical credit assignment over research stages, state transitions, and actions. Experiments on five search benchmarks show that FALCA improves long-horizon deep search performance over backbone and harness ablations, while reducing confirmation bias and error accumulation through more effective falsification and research-state revision.

**一句话**：提出FALCA框架，用Searcher-Falsifier协作与证伪感知训练（SFT预热+agentic RL+分层信用分配）提升长时程深度搜索智能体的抗错误累积能力。

> 🔗 **与课题**：主要支撑环节①（长时程任务分解与多步推理/状态维护）和⑥（SFT+agentic RL训练手段，但绑定搜索场景），对⑦评测有搜索基准层面的参考；不涉及③跨域/跨平台能力迁移，也不涉及②结构化DAG生成、④QGIS算子落地、⑤结构化图生成。整体属于通用LLM agent的planning/reasoning与长时程状态修正方法，可作为工作流推理中错误累积抑制的旁证，但不是GIS workflow reasoning或tool grounding的直接研究。

### ⭐⭐⭐ InterWebCoder: Learning Interactive Webpage Generation from Executable Tests via Reinforcement Learning
**6/10** · Jingyu Xiao、Dasen Dai、Yuxuan Wan、Jen-tse Huang、Yintong Huo、Hongyu Zhang · arXiv · 2026-10-20 · [原文](https://arxiv.org/abs/2610.28610v1) · [PDF](https://arxiv.org/pdf/2610.28610v1)

> 📄 **摘要**：Interactive webpages underpin modern applications, but reproducing both their visual appearance and multi-step behavior remains challenging for multimodal large language models (MLLMs). Scalable training data must capture user actions, state transitions, and expected outcomes, while real-world webpage code is often entangled with irrelevant scripts and external dependencies. Moreover, existing GUI-agent-based verification provides slow and potentially unstable functional feedback. To address these challenges, we propose InterWebCoder, an efficient framework for interactive webpage code generation. InterWebCoder introduces a Test-Specification-Guided and Execution-Verified Data Synthesis pipeline that records real-world interaction trajectories and synthesizes self-contained webpage code with executable test scripts. A failureattributed repair mechanism uses runtime evidence to locate and iteratively fix errors in either the webpage code or test script. We then combine test-ID-weighted supervised fine-tuning with group-relative policy optimization, directly optimizing functional correctness and visual fidelity using test pass rates and state-level visual similarity. This replaces costly GUI-agent verification with fast, reproducible executable feedback. Our pipeline produces 1,736 verified samples from 2,058 tasks, achieving an 84.35% synthesis success rate. On IWR-Bench and Vision2Web, InterWebCoder achieves final scores of 48.54 and 48.42 with a 9B backbone, outperforming 30B-level models and Gemini-3.7-Flash while remaining competitive with Claude-Sonnet-5. It reduces reward-computation latency by over 97%, eliminates external MLLM verification costs, and accelerates end-to-end training by up to 1.4x.

**一句话**：提出 InterWebCoder 框架：用由测试规格引导、经执行验证的数据合成管线，加上以测试通过率与状态级视觉相似度为奖励的 SFT+GRPO 训练，提升多模态大模型生成可交互网页代码时的功能正确性与视觉保真度。

> 🔗 **与课题**：支撑⑥训练/后训练与⑦评测两个环节：其一，用可执行测试作为快速、可复现的功能正确性反馈替代不稳定的 GUI-agent 验证，这一思路可直接类比为本课题的“执行成功率”指标，以及 QGIS processes+links 图的可执行性验证协议；其二，test-ID 加权 SFT + group-relative 策略优化属于“把奖励绑定到可执行性”的训练范式，可作为 ⑥ 中后训练奖励设计的参考；其三，failure-attributed repair 用运行时证据做错误定位与迭代修复，可迁移到 QGIS 落地阶段对幻觉算子、参数错误、依赖断裂做错误归因与自动修复循环，服务 ④⑤。但全文不涉及工作流推理/任务分解（①）、跨平台能力迁移（③）、tool/operator grounding（④ 的核心语义对齐），任务域为网页代码与视觉保真，因此仅属支撑环节的通用方法，落在 5-7 档。

⚠️ **局限**：任务域与评测基准（IWR-Bench、Vision2Web）完全面向网页代码与视觉相似度，奖励质量强依赖可执行测试的覆盖度，且未触及工作流推理与跨平台迁移。

### ⭐⭐ Embodock: A robust embodied language-driven framework for vision-based AUV docking in turbid waters with zero-shot generalization
