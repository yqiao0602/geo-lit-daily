### ⭐⭐⭐ Data supporting Derivation-Relative Structural Admissibility for Pre-Execution Control of LLM-Agent Workflows
**6/10** · Mammuan Alams、Desmond Bala Bisandu、Irene Moulitsas · CERES · 2026-10-30 · [原文](https://doi.org/10.57996/cran.ceres-2885)
*入选：工作流×工具推理*

> 📄 **摘要**：Large language model (LLM) agent systems convert model reasoning into consequential actions such as tool calls, database updates and publication. Existing controls can authorise actions, constrain execution paths and evaluate provenance or relational state. However, a transition may remain structurally inadmissible because of policy-relevant state in the derivation that produced its artefact. We formalise derivation-relative structural admissibility and operationalise it through the Pre-Execution Governance Framework (PEGF), a deterministic architecture that validates dependencies, reconstructs derivation ancestry and evaluates actions before effects occur. Using publication as an evaluated terminal instantiation, PEGF revalidates the consumed draft’s claim–evidence relation against its evidence ancestry and, under an exact-equality policy, requires the relation to preserve that baseline. Across 27 matched configurations, relation-preserving cases were allowed, while all relation-substitution cases were denied with E.ADM.CLAIM_DRIFT after publication-binding checks succeeded. FULL_STAGE2 denied 77/77 structural adversarial traces and preserved 25/25 policy-admissible workflows. On AgentDojo-derived Transfer-B traces, PEGF denied 80/80 adversarial traces and preserved 40/40 benign traces, compared with 16/80 denials by a sequence-only finite-state machine. Across 65 benign traces, PEGF added median control processing of 3.88 ms and 2.22% paired replay overhead. These results support derivation-relative structural control without establishing semantic truth, provenance truthfulness or end-to-end deployment guarantees.

**一句话**：提出预执行治理框架PEGF，形式化"推导相对结构可接受性"，在LLM智能体动作产生副作用前校验依赖与推导谱系。

痛点在于现有控制只能授权动作、约束执行路径或评估溯源，但生成产物的推导过程中仍可能存在策略相关的结构不可接受状态。作者形式化derivation-relative structural admissibility并实现确定性架构PEGF，验证依赖、重建推导祖先、在执行前评估动作。实验显示关系保持的配置全部放行、关系替换全部拒绝，FULL_STAGE2拒绝77/77对抗轨迹并保留25/25合法工作流，AgentDojo Transfer-B上拒绝80/80对抗、保留40/40良性，额外开销约3.88ms与2.22%。

> 🔗 **与课题**：支撑②⑤⑦。②：把工作流的依赖关系与推导谱系显式化并做结构可接受性判定，等同于对"依赖闭合"给出形式化定义与可执行检查；⑤：其"在effects发生前评估"的pre-execution校验可直接作为QGIS processes+links图生成后的把关层，拒绝算子替换、语义漂移这类结构错误；⑦：提供对抗轨迹+良性轨迹的双向评测协议（拒绝率/保留率）与配对重放开销度量，可迁移为"幻觉算子率/依赖闭合率/可执行率"的评测设计。其sequence-only FSM仅拒绝16/80的对照结果说明浅层序列校验不足以捕获结构违规，提示结构正确性评测必须采用图级、依赖级判据。该文不涉及①工作流推理解题过程与③跨平台能力迁移，故不进入8分档。

💡 **启发**：可借鉴其"derivation ancestry + 关系保持(exact-equality policy)"机制，为QGIS图生成设计一个确定性后置校验器：逐节点检查其输入是否由上游links闭合提供，并检测算子/数据源被替换导致的语义漂移。

⚠️ **局限**：面向发布治理场景，策略与"精确相等"判据需人工定义，尚未验证在开放式GIS算子树上的可扩展性与策略自动获取。

### ⭐⭐⭐ Re4: Scientific computing agent with rewriting, resolution, review and revision
**6/10** · Ao Cheng、Lei Zhang、Guo‐Wei He · Machine Learning Science and Technology · 2026-10-29 · [原文](https://doi.org/10.1088/2632-2153/aebb8b)
*入选：工作流×工具推理*

> 📄 **摘要**：Abstract Large language models (LLMs) are a promising class of generative artificial intelligence models and have demonstrated abilities to perform complex tasks in multiple domains, including mathematical and scientific reasoning. In this work, we construct a novel agent framework for solving representative problems in scientific computing. The proposed agent, incorporating a "rewriting-resolution-review-revision" logical chain via three reasoning LLMs (functioning as the Consultant, Reviewer, and Programmer, respectively), is integrated in a collaborative and interactive manner. The Consultant module endows the agent with knowledge transfer capabilities to link problems to professional domain insights, thereby rewriting problem descriptions through text augmentation. The Programmer module is responsible for generating and executing well-structured code to deliver the problem resolution. The Reviewer module equips the agent with the capacity for self-debugging and self-refinement through interactive feedback with code runtime outputs. By leveraging the end-to-end review mechanism, the executable code provided by the Programmer undergoes iterative revision. A comprehensive evaluation is conducted on the performance of the proposed agent framework in solving typical partial differential equations (PDEs), engineering-oriented flow past a cylinder, ill-conditioned linear systems, and data-driven physical analysis problems. Compared with a single-model approach, this collaborative framework significantly improves the bug-free code generation rate and reduces the occurrence of non-physical solutions, thereby establishing a highly reliable framework for autonomous code generation based on natural language descriptions. The review mechanism improved the average execution success (bug-free code and non-NaN solutions) rate of the modern reasoning model DeepSeek R1 from 59% to 82%, while ChatGPT 4.1-mini improved from 66% to 87% and Gemini-2.5 improved from 60% to 84%. Automatic code generation and review provide a promising workflow for scientific computing; analysis of solver-development trajectories further reveals recurring implementation difficulties in boundary treatment, array indexing, and the preservation of numerical constraints.

**一句话**：提出 Re4 多智能体框架，通过 Consultant、Programmer、Reviewer 三个 LLM 协作完成科学计算问题的改写、求解、审查与迭代修订。

针对科学计算问题求解，论文构建了“改写-求解-审查-修订”逻辑链的多智能体框架：Consultant 负责领域知识关联与问题文本增强，Programmer 生成并执行代码，Reviewer 基于运行反馈进行自调试与自精炼。在 PDE、圆柱绕流、病态线性系统和数据驱动物理分析等任务上验证了多模型协作优于单模型。

> 🔗 **与课题**：主要支撑环节①的任务分解/流程规划和④的代码/工具落地：Re4 将复杂科学计算任务拆为改写、求解、审查、修订多阶段，并由 Programmer 生成可执行代码、Reviewer 基于运行反馈迭代修正；对⑦评测也有一定参考（端到端审查与执行反馈）。但它面向科学计算代码生成，不涉及 GIS workflow reasoning、QGIS operator grounding 或跨平台能力迁移，因此仅为通用方法支撑。

💡 **启发**：可借鉴其“Consultant 领域改写 + Programmer 代码落地 + Reviewer 执行反馈修订”的多角色闭环，用于 QGIS processes 生成后的执行反馈自修复与幻觉算子审查。

⚠️ **局限**：论文聚焦科学计算 PDE/数值代码场景，未验证工作流结构生成、跨平台迁移保持率或 GIS 算子 grounding，引用时需说明领域差异。

### ⭐⭐⭐⭐ From Harness Optimization to Recursive Self-Improvement: A Survey of Language Model Agents
**7/10** · Xin Yu、Chengyuan Liu、Wenxin Long、Haochen Zhang、Lingzhou Xue · Preprints.org · 2026-10-30 · [原文](https://doi.org/10.20944/preprints202610.2293.v2)
*入选：工作流×工具推理*

> 📄 **摘要**：Language-model agents rely on harnesses that govern tool use, context, memory, and execution. Understanding automated harness revision requires connecting improvement methods to the reusable functionality they produce. This survey examines three linked perspectives: improvement workflows, recursive scope, and concrete modifications across task domains. We compare search strategies, memory management, edit guidance, and integration with model training, and use an existing five-level framework to distinguish harness optimization from recursive self-improvement. Across coding, reasoning and information processing, interactive and embodied tasks, and visual tasks, we trace reported changes from starting capabilities to outcomes. Our synthesis identifies repairs at model–environment interfaces, cases where added tools and context fail to help, and conditions constraining recovery reuse. Cross-domain analogies motivate, rather than establish, transfer. We distinguish task-performance gains from improved subsequent optimization and identify priorities in reliable evaluation, attribution, transfer, and safety.

**一句话**：一篇综述，系统梳理语言模型智能体的 harness（工具使用、上下文、记忆、执行）自动修订与递归自我改进的方法、范围与跨任务实证。

针对智能体改进方法与其产生的可复用功能之间脱节的问题，该综述从改进工作流、递归范围、具体修改三个视角比较了搜索策略、记忆管理、编辑指导以及与模型训练的集成，并用五级框架区分 harness 优化与递归自我改进。在编码、推理、交互与具身、视觉等任务域追踪从初始能力到结果的改动，指出模型与运行环境接口处的修补、新增工具与上下文无益的情形、以及恢复复用的限制条件。最终区分任务性能提升与后续优化能力提升，并提出可靠评测、归因、迁移与安全的研究优先级。

> 🔗 **与课题**：主要支撑③（迁移）与⑦（评测），并间接涉及⑥与 agent/harness 层面的 tool use。对③：论文明确指出跨域类比只能“激发”而不能“确立”迁移，并把 transfer 列为待解决优先级，这与我们关心的 GEE→QGIS 能力迁移保持率问题同构，可作为迁移证据标准与归因方法论的引用来源。对⑦：它将“任务性能提升”与“后续优化能力提升”分离，并提出可靠评测与归因议题，可直接映射到我们对工作流推理质量、迁移保持率、QGIS 落地可用率的指标设计。对⑥/agent：harness 层的工具、上下文、记忆、执行组件对应于我们 grounding 阶段的接口修补与失败模式（如新增工具却无增益）。但它不涉及工作流推理的结构化表示（②）、依赖图生成（⑤）或具体算子 grounding（④），也没有 GIS 实验。
